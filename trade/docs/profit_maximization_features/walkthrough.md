# 利益最大化機能（トレイリングストップ＆MTF分析） 実装完了のご報告

## 実装した機能の概要
ご要望の通り、機関投資家レベルの利益最大化・リスク回避ロジックをシステムに組み込みました！

### 1. トレイリングストップ（利益追従システム）
- これまではRSIが設定値（例：70）を超えた時点で**即座に利益確定**していましたが、これからは**「利益追従（トレイリング）モード」**が起動するようになります。
- 起動後はAIが「最高値（FXの場合は最安値）」を常に記憶し続けます。価格が伸び続ける限りは絶対に決済せず、天井から設定した値幅（デフォルト 1.0%）反発した瞬間に自動で利確します。
- これにより、「売った直後にさらに爆上がりして悔しい思いをする」ことがなくなり、大きなトレンドの波を最後まで取り切ることができます。

### 2. マルチタイムフレーム（MTF）分析
- これまでの5分足の監視に加え、新たに「1時間足」のマクロトレンド（大局）を監視するようになりました。
- **📉 1時間足が完全な下落トレンドの時**: どれだけ5分足で「買いシグナル」が出ても、一時的な騙し上げ（デッド・キャット・バウンス）と判断して**現物買いをストップ**します。
- **📈 1時間足が完全な上昇トレンドの時**: 安易な逆張りによる踏み上げ（爆損）を防ぐため、**FXの空売りをストップ**します。

### 3. ダッシュボードUIの拡張
- ダッシュボードのMACD指標の下に、**「大局トレンド (上位1時間足)」**のリアルタイム判定バッジを追加しました。現在のシステムがどちらの目線で動いているかが一目でわかります。
- **⚙️AIシステム パラメーター設定**の中に、**「📈 トレイリングストップ 発動幅 (利益追従)」**のスライダーを追加しました！
- ここで「最高値から何％下がったら利確するか」を 0.1% 〜 5.0% の間で自由に変更可能です。「安全重視」「標準」「攻め」のプリセットボタンを押すと、このトレイリング幅もそれぞれの運用スタイルに合わせた最適値（1.5%, 1.0%, 0.5%）が自動セットされます。

## ご確認いただきたいこと
ダッシュボード画面をリロード（更新）していただき、以下の点をご確認ください。
- 「大局トレンド」のバッジが表示されていること。
- 設定（歯車アイコン）を開き、トレイリングストップの設定スライダーが追加されていること。
- 設定を変更し「保存」を押して、正常に適用されること。
