# 利益最大化機能（トレイリングストップ＆MTF分析）の実装計画

## 概要
現在のデュアルエンジン（現物買い＋FX空売り）システムに対して、以下の2つの強力な機能を追加し、利益の最大化とリスクの最小化を図ります。

1. **トレイリングストップ機能**
   これまでは「RSIが指定値に達したら即利確」していましたが、これを「RSIが指定値に達したらトレイリングモードを起動」するように変更します。価格が伸び続ける限りはどこまでも利益を追求し、天井・大底から一定割合（例：1.0%）反発した瞬間に利確します。
2. **マルチタイムフレーム（MTF）分析機能**
   これまでの5分足に加え、1時間足（上位足）のMACDトレンドを解析します。「大局が完全な下落トレンドの時には現物を買わない」「大局が完全な上昇トレンドの時には空売りをしない」というフィルターをかけ、無駄な損失（高値づかみ・底値売り）を激減させます。

## 変更予定のファイル群

### `api_server.py`
- `bot_state` にトレイリングストップの状態（起動中フラグ、最高値、最安値など）を記録する領域を追加。
- 5分足データ取得の直後に、**1時間足（1hour）のローソク足データ**も取得し、1時間足レベルのMACD（マクロトレンド）を計算する処理を追加。

### `strategies/decision_maker.py`
- **MTFフィルターの実装**:
  - `macro_trend == "DOWN"` の場合、現物買い（Spot Buy）を抑制。
  - `macro_trend == "UP"` の場合、FX空売り（Margin Short）を抑制。
- **トレイリングストップの実装**:
  - 【現物】RSI >= `rsi_sell` でトレイリング起動。最高値を更新し続け、最高値からX%下落したら利確。
  - 【FX】RSI <= `rsi_buy` でトレイリング起動。最安値を更新し続け、最安値からX%上昇したら買戻し。

### `dashboard/index.html` & `dashboard/app.js` (ダッシュボード)
- 上位足（1時間足）の現在のマクロトレンドがどちらを向いているか、画面上にわかりやすく表示するバッジを追加。
- （ご希望の場合）設定画面にトレイリングストップのパラメーター設定項目を追加。
