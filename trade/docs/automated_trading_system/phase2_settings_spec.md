# Phase 1.5: UI設定パネル（動的パラメータ変更）仕様案

現在バックエンドのPythonプログラムに直接書き込んでいる「運用予算」や「判定シグナル」の具体的な閾値を、ダッシュボードの画面上からスマホ・PC問わずリアルタイムで調整可能にする拡張機能の仕様案です。

## 1. UI（フロントエンド）の追加要件
スマホ版のボトムナビゲーションおよびPC版のヘッダー付近に **「⚙️ 設定」** タブを新設し、以下の数値を自由に変更・保存できる専用のコントロールパネルを用意します。

### 調整可能にするパラメータ一覧
| パラメータ名 | 概要 | デフォルト値 | 変更ステップ |
| :--- | :--- | :--- | :--- |
| **運用限度予算** | ボットに任せる最大予算（日本円） | `100,000` | 10,000円単位 |
| **1回の購入割合** | 予算に対する1回の買い付け額割合 | `20%` | 5%単位 (10%〜50%) |
| **フルポジ上限** | 予算の何%まで現物保有を許容するか | `85%` | 5%単位 (50%〜100%) |
| **RSI 買い基準** | RSIがいくつを下回れば「買い」とするか | `45` | 1単位 (30〜50) |
| **RSI 売り基準** | RSIがいくつを上回れば「売り」とするか | `70` | 1単位 (60〜85) |
| **強欲ストッパー** | Fear & Greed Indexがいくつを超えたら買いを無効にするか | `75` | 1単位 (60〜90) |

## 2. API（バックエンド）の追加要件
Flaskサーバー側に、フロントエンドのダッシュボードとの間で設定値をやり取りするための専用エンドポイントを実装します。

* `GET /api/settings`: 現在のシステム設定値を読み込み、UIパネルのスライダー等に反映させる。
* `POST /api/settings`: UIの「変更を保存」ボタンを押した際にパラメータを受け取り、即座にAIのメインロジックへと反映させる。

## 3. 設定値の保存方法（永続化）
プログラムおよびPCを再起動した際に昨日の設定が初期化されないよう、Python内のデータを `config/bot_settings.json` という専用ファイルへ自動的に保存し、次回起動時に読み込む堅牢なロジックを実装します。

## 4. プログラムの改修範囲
* `dashboard/index.html` および `dashboard/app.js` (UIデザインと保存非同期処理の追加)
* `api_server.py` (設定用APIエンドポイントの追加)
* `strategies/decision_maker.py` (固定数値 `45` 等を設定値変数に置き換え)
* `execution/order_manager.py` (予算上限などの固定環境変数を置き換え)
