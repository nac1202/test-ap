# くりぷとくん（AI自動売買システム） 運用ルールまとめ

本システム（Phase 1）が相場を24時間監視し、実際に資金を動かす際の「頭脳（ロジック）」と「資金管理ルール」の完全なまとめです。

## 1. 基本設定と対象市場
* **対象取引所**: GMOコイン
* **対象市場**: 取引所（現物取引）の `BTC/JPY`
* **選定理由**: スプレッド（隠し手数料）が極めて狭く、ボット運用での利益率を最大化できるため。
* **予算リミット**: 100,000円（※システム内に設定済みの上限枠）

## 2. 資金管理ルール（分割エントリー方式）
相場の不確実性に対するリスクを徹底的に下げるため、「分割して買い、一気に売る（ノーポジに戻す）」という安全なプロ仕様の設計を採用しています。

* **🟢 買いのルール（打診買い / ナンピン）**
  AIが「買いシグナル」を出した場合、いきなり10万円全額を使うのではなく、予算の **20%（20,000円分）** だけを購入します。
  これにより、購入後にさらに相場が下落した場合でも、より安い価格帯で「追加の2万円」を買い増し、平均取得単価を安全に下げながら戦うことができます。

* **🛑 買いのストッパー（フルポジ制限）**
  保有しているBTCの金額が予算の **85%（85,000円）** を超えた場合、システムは「これ以上の買い増しはリスク過多（フルポジション）」と判断し、以後の買いシグナルを無視して待機します。（予算以上の無限買いを防ぎます）

* **🔴 売りのルール（全額決済クリア）**
  AIが「売りシグナル（利確・または損切り）」を出した場合、中途半端に残すことはせず、現在保有しているBTCを **全量売却して日本円（安全な現金資産）へと一度リセット** します。

## 3. シグナル判定基準（AIの頭脳）
システムは5分足のチャートを常時監視し、以下の3つの指標を組み合わせて行動を決定します。

### 🛒 買いシグナル（※以下のすべてを満たした場合のみ購入）
1. **RSI（相対力指数）が `45未満`**: 相場が一時的に**「売られすぎ・底値圏」**にある。
2. **MACDヒストグラムが `プラス（0超え）`**: 売りの勢いが止まり、**「上昇トレンドに転換」**した瞬間（ゴールデンクロス）である。
3. **Fear & Greed Indexが `75未満`**: 世間が極度のバブル状態（お祭り騒ぎ）ではない。（※危険な**「高値づかみ」**を防ぐためのストッパー機能）

### 💸 売りシグナル（※以下のすべてを満たした場合のみ全額売却）
1. **RSIが `70超え`**: 相場が過熱し、**「買われすぎ・一時的な天井圏」**にある。
2. **MACDヒストグラムが `マイナス（0未満）`**: 上昇の勢いが尽き、**「下落トレンドに転換」**した瞬間（デッドクロス）である。

## 4. 運用上のポイント
* **完全自動・放置可能**: プログラム（黒い画面）さえ起動していれば、ダッシュボードの表示枠を消しても内部で24時間稼働し続けます。
* **手動介入について**: ボットの稼働中にお客様自身の手でGMO証券アプリから直接手動で「売り・買い」を行ってもシステムは壊れません（自動で残高を計算し直して追従します）。ただし、システムが「今は買いタイミングだ」と判断しているゾーンの中で手動で売却すると、すぐにボットが買い直してしまう可能性があるためご注意ください。
