# 実装完了: リアルタイム自動予算追従機能（AUTO/MANUAL）

「ダッシュボードを開いて設定ボタンを押した時」だけでなく、**「システム（裏側）が24時間稼働している間、常に資産の増減を監視し、自動で予算枠を調整し続ける」** 完全自動化（AI運用）の仕組みの実装が完了しました。

## 実装された機能の概要

### 1. 24時間フルタイムの予算最適化
計算エンジンをダッシュボード画面から**サーバー側（APIサーバーのバックグラウンド処理）**に移管しました。
これにより、ユーザーがダッシュボードを閉じて寝ている間でも、システムは常に以下の処理を自動で行います。
*   数秒おきに現在の最新の「総資産額」を計算。
*   総資産額に合わせて、現在の設定モード（例：バランス運用など）に応じた予算枠（現物枠・FX枠・防御枠）を再計算。
*   予算が1万円以上変動したタイミングで、AIの思考ロジック（`bot_settings.json`）を自動で書き換え。
*   （※）資金が少ない場合でも、FXの最小要件である「15万円」を下回らないように下限ガードがかかります。

### 2. AUTO / MANUAL モードの切り替え機能
ダッシュボード画面の予算設定エリア上部に、**「🔄 予算の自動追従 (AUTOモード)」**の切り替えスイッチを追加しました。

*   **AUTO（ON）**: バックグラウンドでシステムが自動的に予算を調整し続けます。また、UI上のスライダーも約10秒ごとにサーバーの最新値と同期（自動でスライダーが動く）します。
*   **MANUAL（OFF）**: 予算の自動調整を停止し、現在の数値で固定します。

### 3. 操作との完全な連動
*   **プリセットボタンとの連動**: 上部にある「守りながらコツコツ」「バランス運用」「積極運用」のいずれかのボタンを押すと、自動的に **AUTOモードがON** になります。
*   **手動操作との連動**: AUTOモード中に、ユーザーが手動で予算のスライダーを動かすと、ユーザーの意思を尊重して即座に **MANUALモードへ切り替わり（OFFになり）**、以後の自動変更が行われなくなります。
