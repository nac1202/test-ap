# リアルタイム自動予算追従機能（AUTO/MANUAL）の実装計画

ご提案ありがとうございます！「ダッシュボードを開いてボタンを押した時」だけでなく、**「システム（裏側）が24時間稼働している間、常に総資産の増減をリアルタイムに監視し、自動で予算枠を拡張・縮小し続ける」** という完全自動化（真のAI運用）の仕組みですね。非常に強力で理にかなった機能です。

この機能を実現するための実装計画を作成しました。

## 課題の背景
現在の実装では、計算はダッシュボード画面（`app.js`）で行われています。つまり、ユーザーがダッシュボードを閉じている間は計算が走らず、利益が出て資産が増えても予算枠は拡張されません。
これを解決するため、計算エンジンを**サーバー側（`api_server.py`）に移管**し、24時間リアルタイムで自動追従させる必要があります。

## Proposed Changes (変更内容)

### 1. サーバー側（`api_server.py`）の改修
- 設定データに `"auto_budget_mode"` （`"manual"`, `"safe"`, `"normal"`, `"aggressive"` のいずれか）を追加します。
- サーバーのループ処理（`bg_updater`）内に予算の自動計算ロジックを追加します。
  - 現在の総資産額を数秒おきにチェック。
  - もし AUTOモード（例: `"normal"`）であれば、総資産に基づいて現物枠・FX枠・防御枠をリアルタイムに計算。
  - 計算結果が現在の設定値と（1万円単位で）ズレていれば、自動的に設定値を上書きして保存し、トレードAI（`decision_maker.py`）に適用します。

### 2. UI側（`dashboard/index.html` & `app.js`）の改修
- **AUTO / MANUAL 切替ボタンの追加**: 予算設定の近くに「🔄 予算の自動追従 (AUTO)」と「手動固定 (MANUAL)」を切り替えるボタン（または表示）を追加します。
- **UIとの連動**:
  - AUTOモード中は、サーバー側で自動計算された最新の予算額がダッシュボードのスライダーにもリアルタイムで反映（同期）されるようにします。
  - もしユーザーが手動でスライダーを動かした場合は、自動的に `MANUAL` モードに切り替わり、ユーザーの手動設定を優先（ロック）する仕組みにします。
  - 上部のプリセットボタン（「バランス運用」など）を押した場合は、対応するパラメーターをセットすると同時に `AUTO` モードをオンにします。

## User Review Required (ご確認事項)

> [!IMPORTANT]
> この実装により、**「プリセットボタンを押すと、自動的に予算のAUTOモードがONになる」** という挙動になります。（手動でスライダーを動かすとOFFになります）。
> また、裏側でサーバーが24時間監視して予算枠を1万円刻みで自動調整し続けます。
