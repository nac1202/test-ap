# 残高に応じたプリセット（運用モード）の動的パラメーター化

おっしゃる通りです！現在の「ワンタッチ設定モード（プリセット）」では、金額枠がハードコード（固定値：40万円など）されているため、ユーザーの口座残高（1万円の人もいれば100万円の人もいる）に合致しないという根本的な問題がありました。

この問題を解決するため、**「現在の総資産額（残高）」をベースにして、金額に関する項目を動的に自動計算する**ようにシステムを改修する計画を提案します。

## 課題の背景と目的
- 現在のプリセットボタンを押すと、予算枠が固定値（現物枠40万など）で上書きされる。
- 口座残高が少ない場合、プリセット適用後に「予算オーバー」となり取引が行われなくなる。
- **目的**: プリセットボタンを押した瞬間の「総資産額」を基準にし、パーセンテージで予算枠を自動計算してスライダーにセットするように改修する。

## Proposed Changes (変更内容)

### 1. `dashboard/app.js`
プリセット機能（`applyPreset`）内で固定の数値をセットするのではなく、現在の総資産額から各予算を算出して適用します。

#### [MODIFY] [app.js](file:///d:/Antigravity/data/trade/dashboard/app.js)
- `currentTotalAssets` というグローバル変数を追加し、`updateDashboard` でAPIから資産額を取得した際に更新する。
- `applyPreset(type)` のロジックを変更し、`currentTotalAssets` を基準に以下の金額設定を自動計算する：
  - **現物 運用限度額 (`limit`)**
  - **FX専用 取り置き資金 (`reserved-margin`)** ※現在プリセットで変更されていなかったため新規追加
  - **FX専用 運用限度額 (`mlimit`)**
- 各モードごとの算出ロジックの目安（※割合は調整可能です）：
  - **守りながらコツコツ (Safe)**: 現物枠=総資産の40%、FX枠=総資産の15%、取り置き(防御枠)=総資産の45%
  - **バランス運用 (Normal)**: 現物枠=総資産の60%、FX枠=総資産の25%、取り置き(防御枠)=総資産の15%
  - **積極運用 (Aggressive)**: 現物枠=総資産の85%、FX枠=総資産の40%、取り置き(防御枠)=0%（全額勝負）

※計算結果は、GMOコインの最小注文要件などを考慮し、極端に小さくなりすぎないような下限ガード（例：最小数万円など）を設けるかどうかも検討します。
