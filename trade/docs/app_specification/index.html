くりぷとくん (Cryptokun)

初心者から上級者まで対応する、プロ仕様の全自動・仮想通貨AIトレードシステム

🌟 システムの概要

「くりぷとくん」は、ビットコイン（BTC）の価格変動を24時間監視し、人間の感情（恐怖や強欲）を排除して全自動で利益を狙うAIシステムです。単なる「安い時に買う」システムではなく、相場の状況に合わせて以下の2つのエンジンを切り替えて戦います。

🟢
現物エンジン（平常時・上昇時）

仮想通貨を「安く買って高く売る」王道のエンジンです。一時的な下落（押し目）を狙って手堅く買い集め、価格が上がったところで確実に利益を確定させます。

🔴
FXエンジン（大暴落時）

市場が大暴落している最中に起動する攻撃用エンジンです。現物買いを停止して資産を守りつつ、「空売り（ショート）」という手法を使って、下落相場すらも利益に変えます。

🛡️ 資産を守る「3つのAIフィルター」

安易なトレードで損をしないよう、プロのトレーダーと同じ視点で相場を監視するフィルターが備わっています。

  • 大局トレンド分析（MTF）
    5分間の短い値動きだけでなく、1時間ごとの「大きな波」を常に確認します。大きな波が下を向いている時（大暴落中）は「落ちるナイフ」と判断し、現物買いをストップして怪我を防ぎます。
  • 恐怖と強欲指数（F&G）ストッパー
    市場全体が「バブル状態（みんなが強欲になっている状態）」を数値で察知し、高値掴み（一番高いところで買わされること）を未然に防ぎます。
  • ダマシ回避フィルター
    「一瞬だけ価格が動いた」ようなフェイク（ダマシ）に引っかからないよう、移動平均線（価格の平均ライン）や直近の高値・安値を計算し、本当にトレンドが変わった確証が持てた時だけエントリーします。

📈 利益最大化の特殊機能

利益を逃さない
トレイリングストップ（利益追従）

目標金額に達してもすぐには売却しません。「価格が伸びている間はどこまでも追いかけ、下落に転じた瞬間に売る」ことで、相場の波を天井から底まで余すことなく利益に変えます。

大底を狙う
セリクラ特攻（逆張り大底拾い）

パニック売りによる歴史的な大暴落が起きた際、通常の防衛フィルターを一時的に解除し、リスクを取って「一番の大底（最安値）」をピンポイントで拾いに行くプロ向けの攻撃機能です。

🎮 ワンタッチ運用モード

専門的な数値がわからなくても、ダッシュボードのボタンを1つ押すだけで、お客様の性格に合わせた最適な設定が自動入力されます。

🛡️ 守りながらコツコツ（安全重視）

無駄なトレードやリスクを極力減らし、本当に安全なタイミングでのみ取引を行う初心者・放置向けモード。FX（空売り）への資金割り当ても少なめです。

⚖️ バランス運用（標準）

最もおすすめの基本設定。リスクをコントロールしつつ、上昇トレンドも下落トレンドもしっかりと利益に変えていく、攻守のバランスが取れたモードです。

🔥 積極運用・上級者向け（攻め）

多少の損切りリスクを許容し、わずかなチャンスでも積極的にエントリーしてリターンを最大化するモード。トレンドが明確な相場で圧倒的な威力を発揮します。

⚙️ 設定画面の各項目の解説

ダッシュボードの「AIシステム パラメーター設定」で調整できる各項目の意味と役割です。

💰 資金管理に関する設定
  • 🟢 現物 運用限度額: 現物買い（Spot）に使える最大予算です。
  • 🔒 FX専用 取り置き資金: いざという時の空売りのために、絶対に現物買いで使わずに温存しておく日本円の枠です。
  • 🔴 FX専用 運用限度額: 大暴落時に空売り（FX）の証拠金として使う枠の最大値です。
  • 1回の打診買い割合: 1回のエントリーで、運用限度額の何%を使うかの設定です。20%なら、最大5回に分けてナンピン（分割買い）します。
📊 エントリー（売買）の基準
  • 現物買い RSI基準: この数値より下がったら「売られすぎ」と判断して現物を買います。（例: 45以下）
  • 現物売却 RSI基準: この数値より上がったら「買われすぎ」と判断して利益を確定させます。（例: 70以上）
  • FX空売り RSI開始基準: 暴落中に一時的に反発し、この数値まで過熱したら空売りを仕掛けます。
⏱️ 連続買い（ナンピン）制限
  • 待機時間 (現物 / FX): 一度トレードしたら、次にトレードするまでの冷却時間です。暴落時に資金が一気に尽きるのを防ぎます。
  • 連続エントリーに必要な値幅: 前回の購入価格から「◯%以上下がらないと次は買わない」というルールです。
⚔️ 特殊機能・リスク管理
  • 📈 トレイリングストップ 発動幅: 利確ライン到達後、最高値（最安値）からこの%分だけ反発した瞬間に決済し、利益を極限まで伸ばします。
  • ⚡ セリクラ逆張り 発動RSI: この数値以下（例: 20）まで異常に暴落した瞬間に限り、AIの警告を無視して全力で底値を拾いに行きます。
  • バブル回避 強欲(F&G)ストッパー: 市場心理がこの数値以上（強欲バブル）の時は、高値掴み防止のため現物買いを停止します。
  • 🚨 絶対防衛ライン (強制損切り): FX空売り時に、含み損が指定した%を超えたら破産を防ぐために全決済（損切り）して逃げます。
