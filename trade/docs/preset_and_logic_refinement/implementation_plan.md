# 設定プリセットと追加ロジックの改善計画

ご提案いただいた設定値と追加条件は、システムの安全性をさらに一段階引き上げる素晴らしい内容です。RSI単体での「ダマシ（偽シグナル）」を減らすためのフィルター条件を追加し、推奨プリセットをすべて反映させます。

## 1. プリセット設定とUIの更新
### [dashboard/index.html & app.js]
- **ボタン名称の変更**:
  - `安全重視` → `🛡️ 守りながらコツコツ`
  - `標準` → `⚖️ バランス運用`
  - `攻めの運用` → `🔥 積極運用・上級者向け`
- **FX運用限度額の追加**: 
  - UIに「FX専用 運用限度額」のスライダー（10万〜50万円）を追加し、プリセットからコントロールできるようにします。
- **内部プリセット値の完全適用**:
  - ご提示いただいた詳細な数値表（RSI、待機時間、値幅、ストップ幅、損切り幅など）を `app.js` のプリセットオブジェクトに完全に反映させます。

## 2. コアロジックの強化（ダマシ回避フィルター）
### [api_server.py]
- 新しいロジック計算のために、過去のローソク足データ（直近の価格推移）を判定エンジン（`decision_maker.py`）に渡すように修正します。

### [strategies/decision_maker.py]
以下の「追加ルール」を実装します。

- **現物買い（Spot Buy）の追加条件**:
  1. `RSI条件を満たす`（既存）
  2. `直近高値（過去100分間など）から一定以上下落している`（新規フィルター）
  3. `短期移動平均（SMA）が下向きすぎない`、または価格がSMAを上抜け始めている（新規フィルター）
  ※セリクラ特例（RSI <= パニックRSI）の場合は、この制限を無視して強行買いします。

- **FX空売り（Margin Short）の追加条件**:
  1. `RSI基準到達`（既存）
  2. `価格が短期移動平均（SMA）を下抜け`（新規フィルター）
  3. `直近安値を割った（ブレイクダウン）`（新規フィルター）

---
これらのフィルターを追加することで、単なる「RSIの数値タッチ」での安易なエントリーがなくなり、より確実なポイント（ダマシの少ないポイント）でのみトレードを行うプロ仕様のロジックに仕上がります。
