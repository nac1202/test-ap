# セリングクライマックス（大暴落パニック）逆張り機能の実装計画

大暴落時に「落ちるナイフ」を避けつつも、パニック売りの最終局面（大底）だけはピンポイントで拾いに行く「特例ルール」をシステムに組み込みます。

## 追加する機能の仕様
通常、1時間足が「下落トレンド」の時は安全のために現物の買いを完全にストップ（MTFフィルター）していますが、**「5分足のRSIが異常な低水準（デフォルト：20以下）に達した瞬間に限り、上位トレンドを完全に無視して特攻（現物買い）する」**というロジックを追加します。

### [api_server.py]
- **設定値の追加**: `bot_settings` に `panic_buy_rsi`（デフォルト: 20）という新しいパラメーターを追加します。

### [strategies/decision_maker.py]
- **ロジックの書き換え**: 現物の購入条件（RSIが設定値以下）の判定部分において、「現在のRSIが `panic_buy_rsi` 以下」である場合は、**強制的にMTFフィルター（大局下落時の買いストップ）を解除**して買いシグナルを発行するようにします。
- **専用ログの出力**: この機能で買った場合は「【セリクラ逆張り】大暴落パニック時の超底値拾いを発動！」という専用のメッセージを出すようにします。

### [dashboard/index.html & app.js]
- **UIへの追加**: ⚙️設定画面に「⚡ セリクラ逆張り 発動RSI（大底拾い）」のスライダーを追加します（10〜30の間で設定可能）。
- **プリセット連携**: 「安全重視」「標準」「攻め」のプリセットボタンを押した際にも、この値が自動で最適な数値（例：安全なら15、攻めなら25など）にセットされるようにJavaScriptを改修します。
