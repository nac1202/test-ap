# UI改修 実装計画 (Implementation Plan)

## 概要 (Goal Description)
現在のダッシュボードUIでは、現物(Spot)とFX(Margin)の残高が分かれて表示されており、システム全体での「現在の総資産額」がぱっと見で分かりにくい状態です。
これを改善するため、アプリの最上部（ヘッダー直下）に「総資産額」を大きく強調して表示するヒーローセクション（Hero Panel）を追加します。

## 変更内容 (Proposed Changes)

### `dashboard/index.html` [MODIFY]
- ヘッダーの下（`<main>`の先頭）に、総資産額を表示するための新しいパネルを追加します。
- `id="total-assets"` を用意し、非常に大きなフォント（Heroスタイル）で表示させます。
- サブ情報として、「前日からの推移」や「現物/FXの合算であること」の注記を含めます。

### `dashboard/style.css` [MODIFY]
- 新しく追加するヒーローセクション専用のスタイルクラス（`.hero-panel`, `.hero-title`, `.hero-value`など）を定義します。
- プレミアム感を維持するため、グラスモーフィズムやグラデーションを用いて視覚的に洗練された（Wow!と思わせる）リッチなデザインにします。

### `dashboard/app.js` [MODIFY]
- `updateDashboard()` メソッド内でサーバーから受け取る `data` を元に総資産額を計算します。
- 計算式: `総資産 = 現金残高(JPY) + 保有BTC現在価値 + FXポジション評価損益` （`api_server.py`側の推移グラフと同じ計算ロジック）
- アニメーション付きで表示を更新する処理を追加します。

## Verification Plan (確認計画)
1. ブラウザで `http://localhost:5000/` (またはCloudflare URL) にアクセスする。
2. ダッシュボードの最上部に「総資産額」が大きく美しく表示されているか確認する。
3. 表示されている総資産額が、「総合評価額推移グラフ」の最新の値、および各パネル（現金+BTC+FX損益）の合計と一致しているか確認する。
