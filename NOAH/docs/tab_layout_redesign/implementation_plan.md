# ページレイアウト（タブ化）改善計画

## 現状の課題
現在のトップページは、以下の要素がすべて縦に並んでおり、特に「週間スケジュール（30日分）」が表示されることで縦長になりすぎています。

- ヘッダー（ロゴ、住所、タロット・コレクションボタン）
- 只今の空席状況（または営業時間外メッセージ）
- みりゅうママからの伝言
- 本日のキャスト
- 週間スケジュール（キャスト予定・お客様ご予約）

縦長のページはスクロールの手間が増えるため、情報の種類ごとに「タブ」で切り替えるレイアウトへの変更は非常に有効なアプローチです。

---

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> タブ化にあたり、以下の3つのUI案（A, B, C）からお好みのスタイルをお選びください。

### 案A: アプリ風 ボトムナビゲーション（おすすめ）
スマホアプリのように、画面の下部に常に固定されたアイコン付きのナビゲーションバーを配置します。
- **タブ構成例:**
  1. 🏠 **HOME** (空席状況・本日のキャスト・ママ伝言)
  2. 📅 **SCHEDULE** (週間スケジュールと予約)
  3. 🌟 **TAROT** (占い画面へ直接遷移・またはコレクション表示)
- **メリット:** 片手操作がしやすく、最もリッチで「アプリ感」が出ます。現在ヘッダーにあるタロットボタンもここに移動できるため、一番上がスッキリします。

### 案B: ページ上部のシンプルタブ
ヘッダーのすぐ下に、横並びのタブメニューを配置し、コンテンツを切り替えます。
- **タブ構成例:**
  - `[ 空席状況 ]` `[ 本日のキャスト ]` `[ スケジュール ]`
- **メリット:** 画面の構造がシンプルでわかりやすく、どの端末でも違和感なく動作します。ヘッダーのタロットボタンはそのまま残す形になります。

### 案C: アコーディオン（折りたたみ）方式
タブではなく、縦に長い原因となっている「週間スケジュール」をデフォルトで折りたたんでおき、「開く」ボタンを押したときだけ表示されるようにします。
- **メリット:** 現状のデザインを大きく変えずに、縦長問題だけを素早く解決できます。

---

## 提案する変更内容（案AまたはBを選択した場合の共通変更）

1. **コンテンツの分割 (`index.html`)**
   現在の縦積みになっている `view-open` (空席)、`cast-section` (本日のキャスト)、`weekly-section` (スケジュール) などを、それぞれ独立した「タブコンテンツパネル」として定義します。

2. **タブ切り替えロジックの追加 (`script` 内)**
   JavaScriptで、選択されたタブに応じて表示するパネル（`display: block` / `display: none`）を切り替える関数を追加します。現在アクティブなタブの状態はブラウザに記憶させ、リロード時にも同じタブが開くようにします。

3. **スタイルの調整 (`style.css`)**
   選択したUI案に合わせて、タブボタンやボトムナビゲーションのデザイン、アニメーション（フワッと切り替わるなど）を追加します。

ご希望の案（A、B、C、あるいは別の分け方）をお知らせいただければ、それに沿って詳細な実装（コード変更）を進めます！
