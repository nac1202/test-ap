# 実装完了: トップページのタブ（ボトムナビゲーション）化

## 変更内容
ご指定いただいた「案A（アプリ風 ボトムナビゲーション）」に基づいて、トップページの大幅なレイアウト改修を行いました。

### 1. ボトムナビゲーションバーの追加
画面の下部に常に固定されるナビゲーションメニューを追加し、以下の3つのタブに分割しました。
- 🏠 **HOME**: 現在の空席状況、本日のキャスト、みりゅうママからの伝言などを表示します。（アプリ起動時の初期画面）
- 📅 **SCHEDULE**: これまで縦長の主な原因だった「週間スケジュールとお客様ご予約」をここに格納しました。
- 🌟 **TAROT**: タロット占い機能と、カードコレクション機能へアクセスできる画面です。

### 2. ヘッダーのスッキリ化
これまでヘッダー領域（ロゴや時計の下）にあった「本日の運勢を占う」「カードコレクション」の2つのボタンを **TAROT** タブの中に移動させました。
これにより、トップページを開いた瞬間の画面上部が非常にスッキリし、最も重要な「現在の空席状況」がファーストビューで目に入るようになりました。

### 3. 操作性の向上
- スマホの親指が届きやすい画面下部でタブを切り替えられるため、操作感が大幅に向上しました。
- 最後に開いていたタブはブラウザに記憶されるため、ページをリロードしても同じタブが復元されます。

## 確認方法
1. 本番URLにアクセスし、画面下部にナビゲーションバーが表示されているか確認してください。
2. それぞれのアイコン（HOME, SCHEDULE, TAROT）をタップし、画面が正しく瞬時に切り替わるか試してください。
3. TAROTタブの中に占いボタンとコレクションボタンが移動しているか確認してください。
