# 修正内容の確認 (Walkthrough): みりゅう最終日 お知らせ＆専用予約フォーム

## 1. 実施概要
「10月31日 みりゅう最終日のお知らせ」のイベント案内文および、その場で参加申し込みができる専用予約フォームをトップページの最上部（ヘッダー・時計直下、空席状況の上）に新設しました。

## 2. 変更・実装内容

### ① フロントエンド告知＆予約フォームUI ([public/index.html](file:///d:/Antigravity/data/NOAH/public/index.html))
- **設置場所**: トップページ（`tab-home`）の最上部、時計直下の最も目立つ位置。
- **デザイン**:
  - 銀座NOAの夜の雰囲気に調和するダークグラデーションに、ゴールドと桜色の華やかな記念アクセント。
  - 「SPECIAL ANNOUNCEMENT」のバッジと光彩アニメーションエフェクト。
- **掲載内容**:
  - みりゅう卒業メッセージ、10月中のご来店案内
  - マイボトル・ボトルキープのお客様へのご案内（最終日に飲み干す旨の注意喚起）
  - 3部制タイムテーブル（1部: 13~16時 / 2部: 16~19時 / 3部: 19~22時、飲み放題・料金）
  - スペシャル特典（ワイン・ボトル半額、食べ物持ち込み無料）
- **専用予約フォーム**:
  - 参加の部選択（🌸 1部 / 🌸 2部 / 🌸 3部）
  - お名前（必須、ニックネーム可）
  - 人数選択（1名〜6名以上）
  - 連絡先入力（任意、電話番号またはLINE ID）
  - 「10月31日の予約を申し込む」ボタン
  - 送信処理関数 `submitFarewellReservation(event)`：送信中はローディング状態となり、完了時に専用の完了モーダルを表示。
  - 予約履歴 (`localStorage` および「スケジュール/予約」タブの履歴モーダル) への即時反映。

### ② バックエンド特別予約API ([api/index.js](file:///d:/Antigravity/data/NOAH/api/index.js))
- `/api/reserve` エンドポイントを拡張。
- 10月31日または席タイプが `part1`, `part2`, `part3` の特別イベント予約について：
  - 通常営業時のカウンター（5席）/ ボックス（6席、2名以上）の定員制限をバイパス。
  - 立ち飲みスタイル対応のイベント定員（各部20名枠）として処理。
  - 該当日の営業時間初期値を 13:00 〜 22:00 として自動設定。

### ③ 管理画面の表示対応 ([public/admin.html](file:///d:/Antigravity/data/NOAH/public/admin.html))
- 管理画面カレンダーの予約詳細リストにて、席タイプが `part1` / `part2` / `part3` の予約について、「🌸1部(13-16時)」「🌸2部(16-19時)」「🌸3部(19-22時)」と分かりやすくラベル表示されるように改善。
