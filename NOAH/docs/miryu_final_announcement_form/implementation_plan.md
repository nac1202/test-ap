# 実装計画: みりゅう最終日（10月31日）お知らせ＆専用予約フォーム

## 1. 概要
2026年10月31日の「みりゅう最終日（卒業イベント）」に関するお知らせを、会員制BAR 銀座NOAのトップページ最上部（空席状況の直上、最も目立つ位置）に美麗なデザインで掲載し、お客様がその場で「第1部」「第2部」「第3部」を選択して予約できる専用フォームを構築します。

## 2. 変更対象ファイル
1. [api/index.js](file:///d:/Antigravity/data/NOAH/api/index.js)
   - `/api/reserve` エンドポイントで、10月31日特別イベント用タイプ（`part1`, `part2`, `part3`）を受け付けるように判定を拡張。
   - 通常のカウンター（5席）/ ボックス（6席）上限チェックや「ボックス2名以上」制限を特別イベント枠では回避し、イベント専用の定員（各部20名等、立ち飲み対応）で安全に処理。
2. [public/index.html](file:///d:/Antigravity/data/NOAH/public/index.html)
   - `tab-home` 内の最上部（`clock` 直下、空席状況表示の上）に特設セクション `#miryu-farewell-section` を追加。
   - 記念告知デザイン：ゴールドと淡い桜色のグラデーション、卒業メッセージ、3部制の詳細、スペシャル特典（半額ボトル＆持ち込み無料）のアピール。
   - 専用予約フォーム：
     - 部の選択（ラジオまたはスタイリッシュなボタングループ：1部 13:00~16:00 / 2部 16:00~19:00 / 3部 19:00~22:00）
     - お名前（必須）
     - 人数（1名〜6名）
     - 連絡先（任意）
     - 予約送信ボタン（ローディング・連打防止・完了モーダル連携）
   - JavaScriptでの予約送信関数 `submitMiryuEventReservation()` 実装。
   - 既存の予約履歴表示 (`reservation-history-modal`) で部名が綺麗に表示されるようマッピング処理を追加。
3. [public/admin.html](file:///d:/Antigravity/data/NOAH/public/admin.html)
   - 予約一覧での席タイプ表示において、`part1` / `part2` / `part3` が「第1部」「第2部」「第3部」と日本語で分かりやすく表示されるよう更新。

## 3. UI/UX デザイン方針
- 会員制バーの上品な夜の雰囲気を損なわず、かつ「卒業の特別感・温かみ・華やかさ」が伝わるラグジュアリーなカードデザイン。
- スマートフォン表示に完全最適化（タップしやすいボタングループ、視認性の高い料金・時間表示）。
- フォーム入力はストレスなく簡単に行えるようコンパクトにまとめ、送信後は即座に既存の予約完了モーダルおよび予約履歴へ反映。

## 4. 検証計画
- 予約フォームからの送信テスト（第1部、第2部、第3部）。
- エラーハンドリング（お名前未入力時のアラート等）。
- 予約履歴モーダルでの表示確認。
- 管理画面での10月31日カレンダー予約詳細確認。
