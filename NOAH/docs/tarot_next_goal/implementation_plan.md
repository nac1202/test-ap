# 実装計画：タロットコンプリート後の「次の目標（やり込み要素）」の追加

## 概要
ユーザーが全24枚のタロットをコンプリートした後も、毎日の占いを続けるモチベーションとなるような「次の目標（エンドコンテンツ）」を追加します。

## 提案するアイディア（User Review Required）

> [!IMPORTANT]
> 以下の3つの案から、どの方向性が最もイメージに近いか教えてください。（複数組み合わせることも可能です！）

### 決定した方向性：段階的な上位称号システムの導入
現在のカードの「覚醒（光り方）」システム（5回、10回、20回）に完全に連動させる形で、最終的に「全カード20回以上」まで到達できるような **段階的な称号システム** を作成します！

#### 想定する称号の段階と条件（案）
1. **NOA MASTER** （実装済み）
   - 条件：すべてのカードを 1回 以上引く（コンプリート）
   - デザイン：現状の金色のバッジとオーブ
2. **NOA GRAND MASTER**
   - 条件：すべてのカードを **5回** 以上引く
   - デザイン：プラチナシルバーのバッジ、オーブの量が増加
3. **NOA ROYAL MASTER**（※称号名は仮）
   - 条件：すべてのカードを **10回** 以上引く（全カードが金色に光る状態）
   - デザイン：燃えるような真紅と黄金のバッジ、豪華な背景エフェクト
4. **NOA PERFECT MASTER**（※称号名は仮）
   - 条件：すべてのカードを **20回** 以上引く（全カードが虹色に光る状態）
   - デザイン：神々しい虹色（オーロラ）のバッジと、画面全体が宇宙空間のようになる究極の背景
