# 修正内容の確認：段階的な上位称号システム

## 変更内容の概要
「全24枚を揃えた後」の新たなモチベーションとなるよう、コレクション画面に **段階的な上位称号システム** を実装しました！

### 称号のランクと達成条件
内部で「各カードを何回引いたか」を計算し、最も引いた回数が少ないカードの枚数を基準にランク判定を行います。

1. **NOA MASTER** (全カード1回以上)
   - 枠線：金色
   - オーブ：100個
2. **NOA GRAND MASTER** (全カード5回以上)
   - 枠線：プラチナシルバー
   - オーブ：150個
3. **NOA ROYAL MASTER** (全カード10回以上)
   - 枠線：燃えるような真紅
   - オーブ：200個
4. **NOA PERFECT MASTER** (全カード20回以上)
   - 枠線：神々しい虹色（グラデーションボーダー）
   - オーブ：300個

それぞれランクに応じて、中央に表示される「コンプリート達成」のメッセージ内容も徐々に壮大になっていきます！

---

## 画像素材の保存場所について
称号に応じて表示するバッジ画像を切り替えるように設定しました。
作成いただいた画像は、以下のファイル名で `public/images/` フォルダ内に保存してください。
（※現在画像がない場合は、リンク切れアイコンにならないように透明になるなど、少し表示が崩れる可能性がありますが、画像を配置すればすぐに直ります）

- 5回以上： `badge_noa_grand_master.png`
- 10回以上： `badge_noa_royal_master.png`
- 20回以上： `badge_noa_perfect_master.png`

## 確認方法（テスト手順）

ブラウザの開発者ツール（F12）の `Console` タブを開き、以下のコマンドを実行することで、強制的に「全カードを指定回数引いた」状態にしてテストすることができます。

```javascript
// 全カードを5回引いた状態（GRAND MASTER）にする
for(let i=0; i<24; i++) { localStorage.setItem(`tarot_card_${i}`, JSON.stringify({count: 5})); }
```
```javascript
// 全カードを10回引いた状態（ROYAL MASTER）にする
for(let i=0; i<24; i++) { localStorage.setItem(`tarot_card_${i}`, JSON.stringify({count: 10})); }
```
```javascript
// 全カードを20回引いた状態（PERFECT MASTER）にする
for(let i=0; i<24; i++) { localStorage.setItem(`tarot_card_${i}`, JSON.stringify({count: 20})); }
```

コマンドを実行したあと、再度トップページから「カードコレクション」を開いてみてください！枠線の色やメッセージ、オーブの数が豪華に変化します！
