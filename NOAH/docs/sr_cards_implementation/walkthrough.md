# ノアマスター限定 SRカード機能の実装完了

## 実施内容のサマリー
ノアマスター向けの新しいレアリティ「SR（スーパーレア）」カードとして、四神（青龍・朱雀・白虎・玄武）と麒麟・鳳凰の全6枚を追加実装しました。

### 1. カードデータの追加
- `tarot-data.js` に SR1（青龍）から SR6（鳳凰）までの6枚のデータを追加しました。
- 各カードにはマスター限定の特別なメッセージとラッキーアクションを設定しています。

### 2. 抽選確率とドローロジック
- `tarot.js` の `getOrGenerateDailyResult()` にロジックを追加しました。
- ユーザーが「ノアマスター」(`noa_tarot_master === 'true'`)である場合のみ、**固定2%の確率**で6枚のSRカードの中からランダムに1枚がドローされます。
- SRカードを引いた際は、SPカードと同様の特別なSE（`drawSpAudio`）が鳴るように設定しています。

### 3. UIと演出
- SRカードが表示される際、特別感を出すために以下のCSSエフェクトを適用しました。
  - カード自体がオーラのように輝きながら脈動するアニメーション (`.card-sr`)
  - カード名と番号のテキストが輝きを放ちながら色が変化するアニメーション (`.sr-style`)
- コレクション画面（図鑑）でもSRカードが同様の特別な輝きを放つように対応しています。

### 4. 画像ファイルの設定
画像は以下のファイル名で読み込まれるように設定しています。お手持ちの画像ファイルを `public/images/` フォルダに配置してください。

- **青龍**: `sr_seiryu.png`
- **朱雀**: `sr_suzaku.png`
- **白虎**: `sr_byakko.png`
- **玄武**: `sr_genbu.png`
- **麒麟**: `sr_kirin.png`
- **鳳凰**: `sr_houou.png`

## 次のステップ
- 画像の配置後、ブラウザの開発者ツールなどを使い、`localStorage`の `noa_tarot_master` を `true` に設定して、実際にSRカードがドローされるか、コレクション画面で表示されるかをご確認ください。
