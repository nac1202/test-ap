# ノアマスター限定 SR（スーパーレア）カード実装計画

## 目標
現在のSPカードの上位レアリティとして、ノアマスター（`noa_tarot_master`が`true`のユーザー）だけが引くことができる6枚のSRカード（青龍、朱雀、白虎、玄武、麒麟、鳳凰）を追加します。非常に低い確率で出現し、特別なエフェクトで表示されるようにします。

## 実装内容

### 1. カードデータの追加
#### [MODIFY] `public/js/tarot-data.js`
`tarotDeck` 配列の末尾に、以下の6枚のSRカードを追加します（インデックス 24〜29）。
*   **SR1 青龍 (SEIRYU)** - 覚醒と開拓
*   **SR2 朱雀 (SUZAKU)** - 昇華と飛躍
*   **SR3 白虎 (BYAKKO)** - 守護と決断
*   **SR4 玄武 (GENBU)** - 叡智と真理
*   **SR5 麒麟 (KIRIN)** - 調和と慈愛
*   **SR6 鳳凰 (HOUOU)** - 祝福と奇跡

### 2. 抽選ロジックと演出のアップデート
#### [MODIFY] `public/js/tarot.js`
*   **抽選確率の変更 (`getOrGenerateDailyResult`)**:
    *   `localStorage.getItem('noa_tarot_master') === 'true'` の場合のみ、SRカードの抽選テーブルを追加します。
    *   SRカードの基本出現確率を極めて低く設定します（例: 2%）。
    *   抽選順序は「SR判定 → SP判定 → 通常カード」とします。
*   **効果音 (`playRevealSound`)**:
    *   カードインデックスが 24 以上（SRカード）の場合も、特別な効果音（`drawSpAudio` または可能ならさらに豪華なもの）を再生するように修正します。
*   **UI表示の調整 (`showResult`)**:
    *   SRカードが引かれた際、カード名や番号の表示に特別なCSSクラスを付与する仕組みを追加します。

### 3. SR専用の視覚エフェクト
#### [MODIFY] `public/css/tarot.css` (または関連CSSファイル)
*   SRカードが画面に表示された際の専用エフェクト（オーラ、キラキラしたパーティクル、特別な枠線やテキストシャドウなど）を定義するCSSクラスを追加します。
    *   `.card-sr`
    *   `.sr-text-glow`
    *   `.sr-aura-effect` などのアニメーション

## User Review Required

> [!IMPORTANT]
> **SRカードの出現確率について**
> 現在のSPカードが予約数に応じて 0.2% 〜 3% 程度で変動する仕様になっています。
> 新しいSRカードは、マスター限定であることを踏まえ、**一律「1%〜2%」程度の固定確率**にするか、SPと同様に**予約数で変動させる**か、どちらの仕様がよろしいでしょうか？（計画では一旦固定2%を想定して実装します）

> [!NOTE]
> **演出について**
> SR用の新しい画像素材（専用の神獣イラストなど）は現在無いため、テキストとCSSの光輝くエフェクト（オーラなど）を駆使して「スーパーレア感」を表現する想定です。もし専用の画像をご用意いただける場合は、画像パスを指定する形に変更可能です。

## 検証計画
*   ローカル環境で占い機能（`tarot.html`）を開き、`localStorage` で意図的に `noa_tarot_master = 'true'` に設定。
*   ドロー確率を一時的に 100% に変更し、6種類のSRカードが正常に引けるかテスト。
*   表示、テキスト内容、豪華なCSSエフェクト、SE再生が正常に機能するか確認。
*   コレクション画面（図鑑）にSRカードが正しく追加・表示されるか確認。
