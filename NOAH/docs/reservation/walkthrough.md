# 予約システム導入完了 (Walkthrough)

## 概要
LINE (LIFF) 連携を見据えた座席予約システムを導入しました。
顧客はWebサイト（およびLINEアプリ内ブラウザ）から、30日先までの空席状況確認と予約が可能になりました。

## 実装内容
### 1. 予約API (`POST /api/reserve`)
- **機能**: 新規予約を受け付け、データを保存します。
- **制約**:
    - **Counter**: 最大5名まで。
    - **Box**: 最大6名まで、かつ **2名以上** の利用が必須。
- **排他制御**: 簡易的な在庫チェックを実装（同時リクエストでのオーバーブッキングは許容範囲とする）。

### 2. フロントエンド (`public/index.html`)
- **カレンダー拡張**: 従来の1週間表示から **30日表示** に変更。
- **予約UIの改善**:
    - 各日付カードに「予約」ボタンと「残席数 (カウンター空席数: x / ボックス空席数: y)」を表示。
    - **残りわずか表示**: カウンターまたはボックスの残席が **2席以下** になると、予約ボタンが黄色（「残りわずか」）に変化します。
    - **リストの最適化**:
        - タイトルを「キャストスケジュールとお客様ご予約」に変更。
        - 営業終了後は当日のスケジュールを非表示にし、翌日から表示。
    - 予約モーダルウィンドウを実装。
- **LIFF連携**:
    - LIFF SDKを導入。
    - LINEユーザーIDと名前の自動取得ロジックを実装（ID設定待ち）。

### 3. 管理機能 (`public/admin.html`)
- **予約確認**:
    - 日付ごとの編集モーダル内に「予約一覧」を表示。
    - 予約者名、席種、人数、連絡先を確認可能。
- **予約キャンセル**:
    - 一覧から予約を削除する機能を実装。

## 動作確認手順
1. トップページ下部の **WEEKLY SCHEDULE** を確認。30日分の日付が表示されていること。
2. 「予約」ボタンを押し、フォームに必要な情報を入力して予約を実行。
    - Box席で1名を選択した場合、エラーになることを確認。
3. 予約完了後、再度その日付を見ると残席数が減っていることを確認。
4. 管理画面 (`/admin`) にログインし、該当日のセルをクリック。予約一覧に追加されていることを確認。
5. 管理画面から予約を「削除」し、反映されることを確認。

## 最新のアップデート事項
### 営業日切り替えタイミングの改善（2026/02/24追記）
- **課題**: 午前0時を過ぎた段階でシステム上は「翌日」と判定され、当日夜（前日からの続きの営業）の予約カレンダーが表示されなくなってしまっていた。
- **対応**: APIおよびフロントエンドの仕様を変更し、**「午前0:00 〜 午前6:59」の間はプログラム的に「前日の営業日」として扱う** 処理（論理的営業日）を追加しました。
- **効果**: 深夜〜明け方にアクセスしたお客様でも、当日の営業時間内であれば引き続き予約が可能になります（例: 24日 0:55 にアクセスしても「23日の営業」として予約申込ができる）。
