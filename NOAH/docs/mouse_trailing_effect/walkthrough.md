# 修正内容の確認 (Walkthrough)

## 実装内容
女教皇（10枚）と女帝（20枚）のカード上でマウス（または指）を動かした際に、軌跡に沿って光が追従する「マウス追従（トレイル）エフェクト」を実装しました。

### 1. 豪華さの差別化
- **女教皇（10枚）**: 
  - 軌跡に沿って「黄金の光の玉（オーブ）」がフワッと残り、ゆっくりと上に昇りながら上品に消えていくエフェクトです。
- **女帝（20枚）**: 
  - 軌跡に沿って「虹色に変化する光の玉」が残るのに加え、その周囲に**キラキラと輝く星屑（スパークル）が重力に従って舞い落ちる**超豪華仕様です。マウスを素早く振ることで、大量の魔法の粉が舞い散る様子を楽しめます。

### 2. パフォーマンスへの配慮
イベントの間引き処理（スロットル）を導入し、約30ミリ秒に1回の頻度でパーティクルを生成するように制御しました。これにより、マウスを激しく動かしてもブラウザが重くなることなく、滑らかで綺麗なエフェクトを描画し続けます。

## 確認のお願い
- ブラウザを**リロード（再読み込み）**していただき、女教皇と女帝のカードの上をマウスでなぞってみてください。
- それぞれのレベルで異なる「光の残り香」の演出をお楽しみください！
