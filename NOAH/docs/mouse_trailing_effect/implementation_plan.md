# 実装計画：マウス追従の光エフェクト（Mouse Trailing Effect）

## 目標
女教皇（10枚）と女帝（20枚）のカード上をマウス（または指）でなぞった際に、軌跡に沿って光の粒子がついてくるエフェクトを実装します。レベルに応じて豪華さを変化させ、インタラクティブな楽しさを強化します。

## 提案する変更

### 1. `public/js/particles.js` の修正
- 画面全体に `pointermove`（マウス移動およびタッチ移動）のイベントリスナーを追加します。
- ポインターが `.glow-gold` または `.glow-rainbow` のカード上にある時だけ、ポインターの座標に小さなパーティクル（光の粉）を動的に生成します。
- パフォーマンスが低下しないよう、移動距離や時間を間引いて（スロットル処理）適度な量だけ発生させる工夫を入れます。

### 2. 豪華さの変化（女教皇 vs 女帝）
カードのレベルに応じて、生成するパーティクルの種類と挙動を変えます。

- **女教皇（10枚）**: 
  - **「黄金の残り香」**
  - マウスの軌跡に沿って、柔らかい黄金の光の玉（オーブ）がフワッと残り、ゆっくりと上に昇りながら消えていきます。上品で神聖な動きです。
- **女帝（20枚）**: 
  - **「虹色の魔法の粉」**
  - 軌跡に沿って虹色に輝く光の玉が残るだけでなく、さらに**小さなキラキラした星屑**が周囲に舞い散ります。マウスを振ると、まるで魔法の杖を振ったかのように大量の光の粉がキラキラと尾を引く、非常に豪華なエフェクトです。

### 3. `public/style.css` の修正
- 生成されるパーティクル用のCSSクラス（`.js-trail-orb`, `.js-trail-sparkle` など）を追加し、フワッと消えるアニメーションや重力に従って落ちる/昇るアニメーションを実装します。
