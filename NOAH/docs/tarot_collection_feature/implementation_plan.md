# タロットカード・コレクション機能 追加計画

## 概要
ユーザーが引いたタロットカードを記録し、後から一覧で確認できる「コレクション（ギャラリー）」機能を追加します。
これにより、毎日カードを引くモチベーションを高め、22枚すべての大アルカナをコンプリートする「ゲーム性・収集要素」を楽しむことができます。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> 以下のオープンクエスチョンについて、ご希望の方向性をお聞かせください。

### オープンクエスチョン
1. **未所持カードの表示方法:**
   コレクション画面でまだ引いていないカードはどう表示するのが良いでしょうか？
   - A. シルエット（カードの形だけグレーアウトし、「？」と表示）
   - B. カードの裏面（共通のカード背面デザインを表示）
   - C. 薄暗い（白黒）状態で表示し、絵柄はうっすら見える状態
2. **コンプリート特典（将来的な拡張）:**
   22枚すべてを集めた際に、特別な演出やシークレットテーマの解放などを用意しますか？（今回は「お祝いのメッセージ演出」のみ実装し、後日拡張なども可能です）
3. **コレクション画面の表示方法:**
   タロット画面内に「コレクションを見る」ボタンを配置し、クリックすると全画面のモーダル（ポップアップ）として一覧が表示される形でよろしいでしょうか？

## 提案する変更内容

### 1. データ保存の仕組み（Local Storage）
- ユーザーがカードを引いた際、そのカードのID（または番号）をブラウザの `localStorage` に保存します。
- これにより、ページをリロードしたり翌日アクセスしたりしても、これまでの収集記録が保持されます。
- 例: `noah_tarot_collection: [0, 2, 5, 13]`

### 2. コレクション画面（UI）
- タロットページのどこか（画面右上や下部など）に「図鑑」や「コレクション」を開くボタンを追加。
- 3列〜4列のグリッド状に全22枚のカードを並べるデザイン。
- **取得済みカード:** フルカラーで表示。クリックすると、そのカードの詳細（意味や拡大画像）を再度確認できる。
- **未取得カード:** 上記オープンクエスチョンの回答に基づく表示（シルエット等）とし、クリックできない状態にする。

### 3. コレクション画面の表示場所と方法
- トップページ（`index.html`）の「本日の運勢を占う」ボタンの下に、「カードコレクション」ボタンを追加します。
- ボタンをクリックすると、トップページ上に全画面（または画面中央）のコレクションモーダルがポップアップとして表示される形とします。

## 検証計画

### 手動検証
- 新規状態でカードを引き、正しくコレクションに追加されるか確認。
- コレクション画面を開き、取得済み・未取得カードが正しく表示されるか確認。
- 取得済みカードをクリックして詳細が読めるか確認。
- テストコード（開発者ツール）を使って全カードを取得済みにし、コンプリート演出が正しく再生されるか確認。
- ページをリロードしてもコレクション状態が維持されているか確認。
