# 実装完了: タロットカードコレクション機能

## 変更内容
ご要望通り、トップページの「本日の運勢を占う」の下に、これまでに引いたタロットカードを一覧できる「カードコレクション」機能を追加しました。

### 1. トップページのUI追加
- `index.html` に「カードコレクション」ボタンを追加しました。
- ボタンをクリックすると、全22枚のカードの収集状況が一覧できるモーダル（ポップアップ）が表示されます。

### 2. データ保存と表示ロジック
- カードを引くたびに、ブラウザのローカルストレージに引いたカードのIDが保存されるように `tarot.js` を修正しました。
- `collection.js` を新規作成し、保存されたデータを読み込んでモーダル内のグリッド表示を動的に生成する処理を実装しました。
- 取得済みカードは本来の画像と名前が表示され、未取得のカードは「？」マークのシルエット表示となります。

### 3. コンプリート機能
- 22枚すべての大アルカナカードを引き当てると、お祝いのメッセージが表示される機能を追加しました。

## 確認方法
1. トップページにアクセスし、「カードコレクション」ボタンが追加されていることを確認してください。
2. コレクション画面を開くと、これまでに引いたことのあるカード（もし以前のバージョンでテストしていたデータが残っていればそれも含む）がフルカラーで表示され、未取得のものは「？」となります。
3. 取得済みのカードをクリックすると、そのカードの簡単な意味が表示されます。
4. （検証用）毎日カードを引いていくと、コレクションが埋まっていき、22種類揃うとコンプリート通知が出ます。
