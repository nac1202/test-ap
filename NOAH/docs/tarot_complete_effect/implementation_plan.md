# 実装計画：タロットコンプリート時の特別演出（リニューアル版）

## 目標
コンプリート時の演出をより豪華にするため、紙吹雪を「大量のオーブ」に変更し、お祝いモーダルをご用意いただいたリッチな画像デザインへ差し替えます。

## 提案する変更内容

### 1. 「オーブが飛び交う」エフェクトへの変更
- 現在の `canvas-confetti`（紙吹雪）を削除します。
- 代わりに、専用のCanvasアニメーション処理をJSで実装し、コンプリート時に「金や白に光る無数のオーブ（光の玉）が画面全体を飛び交う・あるいは下から上へ幻想的に昇っていく」リッチなエフェクトを作成します。

### 2. モーダル画面の画像差し替え
- 現在のHTMLとCSSで組まれたモーダルを廃止します。
- モーダルの中央に、ご提示いただいた豪華な画像をドーンと表示するように `public/tarot.html` を書き換えます。
- 画像下部にある「祝福を受け取る」ボタン部分に合わせて、透明なクリック領域（またはデザインに合わせたボタン要素）を配置し、タップでモーダルが閉じるように調整します。
