# 実装計画：インタラクティブな波紋エフェクト

## 目標
女教皇（10枚）以上のカードをタップした際に、タップした位置を中心にして光の波紋が広がるエフェクトを追加する。
女帝（20枚）の場合は、波紋だけでなく星屑が弾け飛ぶような豪華な演出にする。

## 提案する変更

### 1. `public/js/particles.js` の修正
- 画面全体に `pointerdown`（タップやクリック）のイベントリスナーを追加し、対象が `.glow-gold` または `.glow-rainbow` クラスを持つカードだった場合に波紋を発生させる処理（イベント委譲）を実装します。これにより、後から追加されたカード（一覧画面など）でも確実に動作します。
- タップした座標（X, Y）を計算し、カード内に `div.js-ripple` を動的に追加します。
- **女帝（レインボー）限定の処理**：波紋と同時に、先ほど作成したクロスフレアをタップ位置の周囲に複数個一気に発生させ、豪華な爆発感（弾ける星屑）を演出します。

### 2. `public/style.css` の修正
#### [MODIFY] `style.css`
- 波紋用のアニメーションクラスを追加します。
  - `.js-ripple`：基本的な波紋の形状と拡大アニメーション（`transform: scale(0)` から `scale(3)` 程度へ拡大しながらフェードアウト）。
  - `.ripple-gold`：黄金色に輝く波紋。
  - `.ripple-rainbow`：虹色（あるいは多色）に輝きながら広がる波紋。
