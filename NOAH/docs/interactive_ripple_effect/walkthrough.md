# 修正内容の確認 (Walkthrough)

## 実装内容
女教皇（10枚）以上のカードをタップした際に、光の波紋が広がるインタラクティブなエフェクトを追加しました。

### 1. タップ位置への波紋生成（JavaScript + CSS）
カードをタップ（クリック）した瞬間の座標を取得し、その位置を中心にして波紋が広がる処理を実装しました。
- **女教皇（10枚）**の場合：黄金色に輝く波紋（`.ripple-gold`）が広がります。
- **女帝（20枚）**の場合：多色の虹色波紋（`.ripple-rainbow`）が広がります。

### 2. 女帝専用の「星屑バースト」エフェクト
女帝カードをタップした際は、波紋が広がるのと同時に、**6〜9個の星屑（クロスフレア）がタップ位置から周囲に向かって一斉に弾け飛ぶ**処理（`spawnBurstFlares`）を追加しました。これにより、最高ランクにふさわしい圧倒的なインタラクションが実現されています。

### 3. パフォーマンスと拡張性
波紋や星屑はアニメーションが完了した瞬間にDOMから自動で削除されるため、何度タップしても動作が重くなることはありません。また、イベント委譲（`document.addEventListener`）を使用しているため、一覧画面などで後から読み込まれたカードにも自動的に適用されます。

## 確認のお願い
- ブラウザをリロードしていただき、女教皇または女帝のカードをタップ（クリック）してみてください。
- タップした位置から波紋が広がり、女帝の場合は星屑が弾ける感覚をご確認ください。
