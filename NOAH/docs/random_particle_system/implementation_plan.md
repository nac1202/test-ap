# 実装計画：JavaScriptによるランダムパーティクル生成

## 目標
女帝カードの「クロスフレア（星の瞬き）」をCSSのアニメーションからJavaScriptの動的生成に移行し、完全にランダムな出現ポイント、大きさ、色、そして自然な消え方を実現する。

## 提案する変更

### 1. `public/js/particles.js` の新規作成
- 画面上の `.glow-rainbow` クラスを持つ要素を監視し、一定間隔で `div.js-cross-flare` 要素を動的に追加・削除するスクリプトを作成します。
- 出現位置（XY座標）、サイズ、色（白、黄、シアン、ピンク、紫など）をJavaScriptで毎回ランダムに計算します。
- フェードアウトが完了した要素はDOMから自動的に削除され、メモリに負担をかけません。

### 2. `public/index.html` の修正
- 新しく作成した `particles.js` を読み込むための `<script>` タグを追加します。

### 3. `public/style.css` の修正
#### [MODIFY] `style.css`
- 現在 `glow-rainbow::after` に固定で書き込まれているクロスフレア（`radial-gradient`）の記述を削除します。
- 動的生成されるパーティクル用のクラス `.js-cross-flare` のデザインとアニメーション（その場でフェードインし、少し上昇しながらフワッと消える動き）を新たに追加します。

## ユーザー確認（User Review Required）
既存の「CSSだけで動かす」構成から、JSの制御ファイルを1つ追加する形になります。カード一覧や詳細画面など、どの画面でも自動で動作するような安全な仕組みにします。この実装方針で進めてよろしいでしょうか？ 問題なければ承認をお願いします。
