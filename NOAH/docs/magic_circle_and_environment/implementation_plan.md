# 魔法陣エフェクトと環境（時間）連動システムの実装計画

タロット占いの演出をさらにリッチにするための追加機能を実装します。

## 実装内容
1. **魔法陣の展開演出**: カードをタップしてめくる直前に、カードの背後に魔法陣が浮かび上がり回転するアニメーションを追加します。
2. **リアルタイム時間連動システム**: ユーザーの現在時刻（朝・昼・夕方・夜）に合わせて、背景のトーンと環境音（BGM）をダイナミックに切り替えます。

> **User Review Required（素材のご準備のお願い）**
> 今回の演出追加に伴い、以下の「画像1点」「音声5点」のご準備をお願いいたします。
> ご用意いただきましたら、指定のフォルダ（`public/images/` および `public/audio/`）に配置してください。

### ご用意いただく素材一覧

#### 1. 魔法陣の画像（1点）
- **ファイル名**: `magic_circle.png`
- **保存場所**: `public/images/`
- **仕様**: 背景が透過された正方形の魔法陣画像。光って見えるような白や金色の単色・ネオン調がおすすめです。

#### 2. 魔法陣展開時の効果音（1点）
- **ファイル名**: `magic_circle.mp3`
- **保存場所**: `public/audio/`
- **仕様**: シュオン！といった魔法陣が展開する際の効果音（1〜2秒程度）。

#### 3. 時間帯ごとの環境音/BGM（4点）
- **保存場所**: すべて `public/audio/` に配置してください。
- **仕様**: ループ再生して違和感のない環境音やBGM。
  1. `bgm_morning.mp3` : 朝（5:00 - 11:59） 例：小鳥のさえずり、爽やかな風
  2. `bgm_day.mp3` : 昼（12:00 - 16:59） 例：穏やかな環境音、静かな波の音
  3. `bgm_evening.mp3` : 夕方（17:00 - 18:59） 例：ひぐらしの鳴き声、夕暮れの風
  4. `bgm_night.mp3` : 夜（19:00 - 4:59） 例：秋の虫の音、フクロウ、静寂な星空の音

## 修正予定のファイル

### `public/tarot.html`
- **[MODIFY]**: 魔法陣を表示するためのDOM要素（画像枠）を追加します。

### `public/css/tarot.css` または `public/style.css`
- **[MODIFY]**: 魔法陣が回転しながら浮かび上がるCSSアニメーション（`spin-and-glow`等）を追加。
- **[MODIFY]**: 時間帯ごとの背景色・オーバーレイを切り替えるためのクラス（`.bg-morning`, `.bg-night` など）を追加。

### `public/js/tarot.js`
- **[MODIFY]**: 初期ロード時に現在時刻を取得し、適切な環境音BGMの再生（ループ）と背景クラスの適用を行います。
- **[MODIFY]**: カードタップ時の処理に「魔法陣展開フェーズ」を挟み込み、魔法陣のSEとアニメーションを再生してからカードめくりに移行するよう制御フローを変更します。
