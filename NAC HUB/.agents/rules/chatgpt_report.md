# ChatGPT報告用テキストの作成

- ユーザーへの最終報告のたびに、ChatGPTへそのままコピー＆ペーストできる報告用テキストを、
  追加で作成して提示する。
- 形式: 4バッククォート（````）で囲んだ1つのMarkdownコードブロックにまとめる
  （内部に通常のコードブロックが入っても崩れないようにするため）。
- 内容: 現在の状態（Version / Commit / Tag / Git / Docker / health）、実施内容、テスト結果、
  秘密情報の扱い、コミット、未完了・残存事項、次にユーザーが行う作業を含める。
  失敗・未完了・エラーは成功扱いにせず、正確に記載する。
- 秘密情報（APIキー・パスワード・トークン等の実値、先頭末尾、文字数）は絶対に含めない。
- 単純な質問への一言回答など、報告に値しないやり取りでは省略してよい。
- 日本語で作成する。
