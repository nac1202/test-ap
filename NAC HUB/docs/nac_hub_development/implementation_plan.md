# 実装計画：NAC HUB UIモックアップフェーズ

本番のロジックやAPI連携を組み込む前に、ご要望いただいた13画面の「静的UIモックアップ」を作成し、UI/UXの方向性をすり合わせます。

## Goal
*   指定された13画面のUIをReact + Tailwind CSSで静的（API通信なし・ダミーデータ）に実装する。
*   「ポップで親しみやすい」「カードUI」「オレンジ・白・淡いグレー」「余白多め」のデザイン方針を徹底する。
*   「なっくん（AI）」「SYSTEM MODE」「ウィジェット方式」などの新要件を視覚化する。

## User Review Required
> [!IMPORTANT]
> 13画面のモックを一気に作成します。以下のルーティング構成や、ナビゲーション（サイドバー等）の配置方針について違和感がないかご確認ください。

## 画面構成・ルーティング方針
確認がしやすいよう、サイドバーメニューからすべてのモック画面へアクセスできるようにします。

1. **ログイン画面** (`/login`)
2. **ホーム画面** (`/`): ウィジェット（天気、予定、タスク、AI、システムリンク）を配置。
3. **AIコンシェルジュ「なっくん」チャット画面** (`/chat`): 会話形式のUI。
4. **案件一覧画面** (`/projects`): ステータスラベル、プログレスバーを含むカードまたはテーブルUI。
5. **案件詳細画面** (`/projects/1`): 基本情報＋タイムライン領域（履歴UI）。
6. **お知らせ一覧画面** (`/notices`): 掲示板形式UI。
7. **通知センター画面** (`/notifications`): 画面右から引き出すドロワー、または独立画面。
8. **HotBizリンク集画面** (`/hotbiz`): タイムカードや設備予約等のアイコンリンク集。
9. **ユーザー管理画面** (`/settings/users`): 一覧と追加/編集UI。
10. **ロール・権限管理画面** (`/settings/roles`): 権限マトリクスのUI。
11. **システム設定画面** (`/settings/system`): Companyマスタ、バージョン情報等のUI。
12. **プラグイン管理画面** (`/settings/plugins`): Slack等のON/OFFスイッチと設定。
13. **監査ログ画面** (`/settings/audit`): いつ誰が何をしたかのシステムログ一覧。

## 共通レイアウト (Layout)
*   **ヘッダー**: ユーザー情報、通知アイコン。システム管理者ログインを想定した状態では赤やオレンジの目立つ帯域で「SYSTEM MODE」と表示。
*   **サイドバー**: 上記2〜13の画面へ遷移できるナビゲーションメニュー。

## Verification Plan
*   すべてのコンポーネントを作成後、ブラウザ上で実際に全画面を回遊・クリック（画面遷移のみ）できるようにします。
*   作成完了後、ウォークスルーを通じてUIをご確認いただきます。
