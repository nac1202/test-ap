AIコンシェルジュ 導入マニュアル

貴社Webサイトに「AIコンシェルジュ」を導入する手順について解説します。
お客様の環境やご要望に合わせて、2つの導入方法からお選びいただけます。

💡 どちらを選べばいいですか？
  • 方法A（推奨）：とにかく簡単に手早く導入したい場合。ファイルのアップロードが不要です。
  • 方法B（標準）：自社サーバーでファイルを管理したい場合。インターネット接続制限がある閉域環境などの場合。
方法A：かんたん設置プラン 推奨
方法B：ファイル納品プラン 標準

方法A: かんたん設置（ファイルアップロード不要）

CDNサーバー上の最新ファイルを直接読み込みます。お客様はHTMLにコードを追記するだけで導入完了です。

1

HTMLファイルを開く

導入したいページのHTMLファイル（index.html 等）をテキストエディタで開きます。

2

CSS・JSコードの追記

</body> タグ（ページの終わり）の直前に、以下のコードをそのまま貼り付けてください。

<!-- AI Concierge Widget (CDN版) -->
<link rel="stylesheet" href="https://bunbun-burger.vercel.app/assets/css/style.css?v=20260205_v1">
<script src="https://bunbun-burger.vercel.app/assets/js/widget_v6.js?v=20260205_v1"></script>
<script>
  window.addEventListener('DOMContentLoaded', () => {
    initConciergeWidget({
      brandName: "貴社の店舗名",
      businessType: "generic", // restaurant / retail / salon / generic
      hours: { open: 11, close: 22 }, // 営業時間
      // 必要に応じてテーマカラーを変更できます
      // themeColor: "#4169e1", 
      // アバター画像をURLで指定できます
      // avatar: { 
      //    desktop: "https://example.com/my-avatar.png", 
      //    mobile: "https://example.com/my-avatar-small.png" 
      // },
      apiUrl: "https://bunbun-burger.vercel.app/api/chat"
    });
  });
</script>
3

動作確認

ファイルを保存し、ブラウザでページを開いて右下にアイコンが表示されれば完了です。

方法B: ファイル納品（セルフホスティング）

納品ファイルを貴社サーバーにアップロードして利用する方法です。

1

ファイルのアップロード

同梱のファイル（ZIPを解凍したもの）を、WebサイトのHTMLファイルと同じ場所（または適切なアセットフォルダ内）にアップロードしてください。

📂 フォルダ構成のイメージ
index.html がある場所に assets フォルダを置くと、その後の設定がスムーズです。 
サーバー（公開フォルダ）
 ├── index.html       <-- お客様のトップページ
 ├── assets/          <-- ★今回お渡しするフォルダをここに置く
 │    ├── js/
 │    │    └── widget_v6.js
 │    ├── css/
 │    │    └── style.css
 │    ├── assistant.png
 │    └── assistant-55.png
 └── images/          <-- その他のお客様の画像など

アップロードするファイル:

  • assets/js/widget_v6.js
  • assets/css/style.css
  • assets/assistant.png / assistant-55.png
2

HTMLコードの編集

</body> タグの直前に、以下のコードを追加します。
※ファイルのパス（href, src）は、実際のアップロード先に合わせて書き換えてください。

<!-- AI Concierge Widget (自社サーバー版) -->
<!-- CSSのパスを合わせてください -->
<link rel="stylesheet" href="assets/css/style.css">

<!-- JSのパスを合わせてください -->
<script src="assets/js/widget_v6.js"></script>
<script>
  window.addEventListener('DOMContentLoaded', () => {
    initConciergeWidget({
      brandName: "貴社の店舗名",
      businessType: "generic",
      hours: { open: 11, close: 22 },
      apiUrl: "https://bunbun-burger.vercel.app/api/chat"
    });
  });
</script>

🧠 接客ルールの学習（カスタマイズ）

「駐車場はありますか？」「おすすめメニューは？」など、お店独自の質問に答えられるようにするには、HTML内にルールを記述します。
data-store-info 属性を使うと、AIだけが見える「カンペ」を渡すことができます。

記述例（HTMLのどこでもOK）

<!-- AIに教える情報（画面には表示されません） -->
<div data-store-info style="display:none;">
  【重要ルール】
  ・駐車場は3台分あり、無料です。
  ・ランチタイム（11:00〜14:00）は全席禁煙です。
  ・「店長のおすすめ」と聞かれたら「てりやきバーガー」と答えてください。
  ・アレルギー対応表はレジカウンターで提示しています。
</div>

💡 ポイント:
・style="display:none;" を付けると、お客様（人間）には見えない状態になります。
・箇条書きなどで具体的に書くと、AIがより正確に答えられるようになります。

応用編：FAQリストを登録する

Q&A形式で明確に教えたい場合は、以下のように記述するとより確実です。

<!-- FAQリスト（複数登録可能） -->
<div data-faq-item style="display:none;">
  <div class="faq-question">予約はできますか？</div>
  <div class="faq-answer">はい、Web予約フォームから24時間受け付けております。</div>
</div>

<div data-faq-item style="display:none;">
  <div class="faq-question">貸切は可能ですか？</div>
  <div class="faq-answer">20名様以上から承っております。お電話でご相談ください。</div>
</div>

⚙️ 設定項目の詳細

initConciergeWidget 内の設定を変更することで、挙動をカスタマイズできます。

項目名 説明 設定例
brandName チャットヘッダーに表示される店舗・企業名です。 "BUN BUN BURGER"
businessType AIの接客スタイルを決定します。
- restaurant（飲食店向け）
- retail（物販向け）
- salon（美容室向け）
- generic（一般） 		"restaurant"
hours 有人営業時間の設定です。時間外は「営業時間外です」と案内しつつ、AI対応を行います。 { open: 9, close: 18 }
themeColor （任意）ブランドカラーを変更できます。指定しない場合は自動検出を試みます。 "#ff0000"
avatar （任意）アバター画像を自社オリジナルのものに変更できます。
PC用とスマホ用（小さめ）の2種類のURLを指定します。

推奨サイズ:
- desktop: 幅170px以上（縦横比自由）
- mobile: 100x100px（正方形推奨）		 avatar: {
desktop: "https://...",
mobile: "https://..."
}
reservationUrl （推奨）自社の既存予約ページ（HotPepper, 食べログ, 自社フォーム等）がある場合、そのURLを指定します。
指定すると、チャット内の予約ボタンがそのページへのリンクに変わります。		 "https://..."
または
"tel:03-1234-5678"
apiUrl AIサーバーの接続先URLです。変更しないでください。 "https://..."
