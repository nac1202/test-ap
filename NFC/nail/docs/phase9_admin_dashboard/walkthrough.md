# Phase 9: Admin Dashboard Implementation - Walkthrough

## 概要
B2B2Cモデルのサロン向け運用管理画面として、`/admin` ダッシュボードをリニューアルしました。
「顧客リスト」を中心としたUIにより、来店したお客様の情報検索や、NFCタグの発行・紐付け業務をスムーズに行えます。

## 実装された機能

### 1. 管理画面レイアウト (`/admin`)
*   左サイドバーによるナビゲーション（Dashboard, 顧客管理, タグ管理）。
*   ダッシュボードTOPには、タグの総発行数やステータス別の在庫状況をカード表示。

### 2. 顧客管理 (`/admin/users`)
*   **一覧表示**: 登録済みユーザーをリスト表示。アイコン、表示名、選択中のテーマ、所持タグ数などを一目で確認可能。
*   **検索機能**: ユーザー名やID、メールアドレスでの検索に対応。
*   **アクション**: 「View」で実際のプロフィールを確認、「Issue Tag」でタグ管理画面へ遷移。

### 3. タグ管理 (`/admin/tags`)
*   Phase 3で実装したタグ機能（発行、無効化、一覧）をこのダッシュボード内に統合。
*   顧客詳細ページから遷移した場合を想定し、UIデザインを統一。

## 技術的変更点
*   `src/app/admin/layout.tsx`: 共通レイアウトの導入。
*   `src/actions/admin.ts`: 管理者用Server Actionsを集約。
    *   `getAdminUsers`: ユーザー一覧取得（Prismaのリレーション構造 `user.profile.tags` に対応）。
    *   `getTags`, `generateTags`: タグ管理ロジックの再配置。

## 次のステップ
*   **顧客詳細ページ**: 一覧からクリックして、そのお客様専用の詳細管理画面（タグ履歴やメモなど）を作ることも可能です。
*   **動的OGP**: 顧客が自分のSNSでシェアしたくなるような仕組み作り（Phase 10予定）。
