# 実装計画: プロフィール画像アップロード機能 (Phase 2)

## 概要
ユーザーがプロフィール画像をアップロードし、プロフィールページに表示できるようにします。
バックエンド（Schema, Server Actions）の実装は完了しているため、フロントエンド（設定ページとフォーム）の実装に焦点を当てます。

## ユーザーレビューが必要な事項
- 特になし（標準的な画像アップロードフローです）

## 変更内容

### 新規コンポーネント
#### [NEW] `src/components/ProfileForm.tsx`
- ユーザープロフィールの編集用フォーム。
- 以下の機能を含みます:
    - 名前、Bio、Handle等のテキスト入力（既存のActionに合わせて実装）。
    - **画像アップロード機能**:
        1. ファイル選択時に `src/actions/upload.ts` の `getCloudinarySignature` を呼び出して署名を取得。
        2. Cloudinary API へ画像を直接アップロード。
        3. 返却されたURLを `avatarUrl` として保持。
    - フォーム送信時に `src/actions/profile.ts` の `updateProfile` を呼び出し。

### 新規ページ
#### [NEW] `src/app/settings/page.tsx`
- ログインユーザー専用の設定ページ。
- `auth()` でセッション確認を行い、`ProfileForm` をレンダリングします。
- 既存のプロフィールデータを取得してフォームの初期値として渡します。

## 検証計画

### 手動検証
1. **設定ページへのアクセス**:
    - `/settings` にアクセスし、未ログインならリダイレクト、ログイン済みならフォームが表示されることを確認。
2. **画像アップロード**:
    - 画像を選択し、プレビューが表示されることを確認。
    - コンソールログ等でCloudinaryへのアップロード成功を確認。
3. **フォーム送信**:
    - 保存ボタンを押し、`updateProfile` が成功することを確認。
    - 完了後、トースト通知またはリダイレクトを確認。
4. **表示確認**:
    - 公開プロフィールページ (`/u/[handle]`) にアクセスし、アップロードした画像が表示されていることを確認。
