# Phase 2 画像アップロード機能 実装確認

## 概要
プロフィール画像のアップロード機能を実装しました。
`src/components/ProfileForm.tsx` で Cloudinary への直接アップロードを行い、URL を `avatarUrl` として保存します。
また、`src/app/settings/page.tsx` を作成し、ユーザーがプロフィールを編集できるページを用意しました。

## 変更点

### フロントエンド
- **[NEW] `src/components/ProfileForm.tsx`**
    - プロフィール編集フォーム。
    - 画像選択 -> Cloudinary への署名付きアップロード -> プレビュー表示 -> 保存 のフローを実装。
    - TypeScript の型安全性（`getCloudinarySignature` の戻り値処理）を確保。
- **[NEW] `src/app/settings/page.tsx`**
    - 認証済みユーザーの設定ページ。
    - 現在のプロフィール情報を初期値としてフォームに渡します。

### バックエンド (修正済み)
- **[MOD] `src/actions/upload.ts`**
    - `getCloudinarySignature` の戻り値をネストされたオブジェクトからフラットなオブジェクトに変更し、フロントエンドでの取り扱いを容易にしました。

## 検証手順

### 1. 開発サーバーの起動
1.  **ターミナルを開く**:
    - VS Code のメニューから [Terminal] -> [New Terminal] を選択するか、ショートカット `Ctrl + ~` (または `Ctrl + shift + @`) を押します。
2.  **コマンド実行**:
    - 以下のコマンドを入力し、Enterキーを押します。
      ```
      npm run dev
      ```
3.  **起動確認**:
    - ターミナルに `Ready in ...` と表示されれば起動完了です。
    - ブラウザで `http://localhost:3000` にアクセス可能な状態になります。

### 2. 設定ページでの動作確認
1.  ブラウザで `http://localhost:3000/settings` にアクセスします。
    - ログイン画面が表示された場合はログインしてください。
2.  **画像のアップロード**:
    - "Profile Image" 部分のファイル選択ボタンを押し、画像を選びます。
    - 少し待つと、選択した画像が丸いプレビューエリアに表示されることを確認します（これがCloudinaryへのアップロード完了を示します）。
3.  **保存**:
    - "Save Changes" ボタンを押します。
    - 画面がリフレッシュされ、変更が反映された状態のままであることを確認します。

### 3. 公開ページでの確認
- ブラウザで `http://localhost:3000/u/[あなたのハンドル名]` （例: `/u/user123`）にアクセスします。
-設定した画像がプロフィールアイコンとして表示されていることを確認してください。

### 4. データベースの直接確認 (詳細確認用)
データが正しく保存されているか、データベースの中身を直接見たい場合の手順です。

1.  **新しいターミナルを開く**:
    - サーバーが動いているターミナルはそのままにして、ターミナルパネル右上の `+` ボタンを押して新しいタブを開きます。
2.  **Prisma Studio 起動**:
    - 以下のコマンドを入力して Enter を押します。
      ```
      npx prisma studio
      ```
    - ブラウザが自動的に開き、データベース管理画面が表示されます。
3.  **データ確認**:
    - "Profile" モデルを選択します。
    - データ一覧の中に自分のユーザーの行を探し、`avatarUrl` カラムに `https://res.cloudinary.com/...` から始まるURLが入っていることを確認します。
