# 実装計画: NFCタグ管理強化 & 書き込み機能 (Phase 3)

## 概要
管理者向けのNFCタグ管理機能を強化し、WebNFC API を利用してブラウザから直接物理NFCタグへのURL書き込みを可能にします。
これにより、専用アプリ不要で管理画面からタグの発行・書き込み作業が完結するようになります。

## 概要
管理者向けのNFCタグ管理機能を強化します。
当初はブラウザからの直接NFC書き込み (WebNFC) を検討しましたが、**iPhone (iOS) が WebNFC 書き込みに非対応** であるため、
**「書き込み用URLの発行・コピー機能」** を実装し、実際の書き込みは iPhone の既存NFC書き込みアプリ (例: NFC Tools) を利用する運用フローを構築します。

## ユーザーレビューが必要な事項
- **運用フローの変更**: iPhoneにはブラウザからNFCを書き込む機能がないため、**「管理画面でURLをコピー」 -> 「別途アプリ(NFC Tools等)で書き込み」** という手順になります。この運用で問題ないか確認が必要です。

## 変更内容

### 1. タグ管理ページの機能強化
#### [MODIFY] `src/app/admin/tags/page.tsx`
- **検索バーの追加**: タグコードや紐付いているユーザー名での検索ボックスを設置。
- **フィルタ**: Status (CREATED, ACTIVE, DISABLED) による絞り込みプルダウンを追加。
- **ページネーション**: `prisma` の `skip`/`take` を使用したページ送り機能を追加。
- **UI更新**: 
    - 各行に「書き込み情報」ボタンを追加。
    - クリックするとモーダルまたは詳細表示で「有効化URL」と「コピーボタン」を表示。

#### [MODIFY] `src/actions/admin.ts`
- `getTags` 関数（または新規作成）を更新し、検索クエリ (`query`)、フィルタ (`status`)、ページ (`page`) 引数を受け取れるようにします。

### 2. 書き込み支援コンポーネント (iOS対応)
#### [NEW] `src/components/admin/TagWriterHelp.tsx`
- **機能**:
    - 対象タグの有効化URL (`https://[domain]/app/activate?code=[tagCode]`) を生成・表示。
    - ワンクリックコピー (`navigator.clipboard.writeText`) 機能。
    - iPhoneでの推奨手順（NFC Toolsアプリ等を開いてURLを書き込む）を表示。

## 検証計画

### 自動テスト
- 検索・フィルタリングロジックの動作確認。

### 手動検証 (iPhone)
1. **管理画面検索・フィルタ**:
    - タグコード検索やステータスフィルタが正しく動くか確認。
2. **書き込みフロー**:
    - 管理画面で「書き込み情報」を開き、URLをコピー。
    - 別途インストールしたNFC書き込みアプリ (推奨: NFC Tools) を起動。
    - "Write" -> "Add a record" -> "URL / URI" を選択し、コピーしたURLをペースト。
    - "Write" をタップし、手元のNFCタグにかざして書き込み完了を確認。
3. **読み取りテスト**:
    - iPhoneのホーム画面に戻り、書き込んだNFCタグを上部（カメラ付近）にかざす。
    - 通知バナー "NFC Tag Detected: Open in Safari" が出ることを確認。
    - タップして自社アプリのタグ有効化ページ (`/app/activate`) が開くことを確認。
