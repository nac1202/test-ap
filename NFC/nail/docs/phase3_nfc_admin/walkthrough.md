# Phase 3 NFC管理機能強化 実装確認
> [!IMPORTANT]
> **Status**: Completed (2026-02-01)
> **Verification**: Verified on iPhone (iOS 17+) with NFC Tools app.

## 概要
管理者向けのタグ管理機能を強化し、iPhone (iOS) でもNFCタグへの書き込み運用が可能なように「URLコピー & 外部アプリ書き込み」フローを実装しました。

## 変更点

### バックエンド
- **[MOD] `src/actions/admin.ts`**
    - `getTags` 関数を更新し、検索クエリ (`query`), ステータスフィルタ (`status`), ページネーション (`page`) に対応。
    - 認証チェック (`ADMIN` ロール) の強化。

### フロントエンド
- **[MOD] `src/app/admin/tags/page.tsx`**
    - 検索バー、ステータスフィルタ、ページネーションUIを追加。
    - 各タグ行に「書き込み情報」ボタンを追加。
- **[NEW] `src/components/admin/TagWriterHelp.tsx`**
    - iOS/Android 共通のNFC書き込み支援コンポーネント。
    - 有効化URL (`/app/activate?code=...`) の生成とコピー機能。
    - 外部アプリ (NFC Tools) を使用した書き込み手順の表示。

## 検証手順

### 0. 事前準備 (PCとiPhoneの接続)
NFCタグへの書き込みと動作確認には iPhone が必要です。以下の準備をお願いします。

1.  **ネットワーク接続**:
    - PCとiPhoneを**同じWi-Fi**に接続してください。
2.  **IPアドレスの確認**:
    - 開発サーバーの起動ログ (`npm run dev`) に表示される `Network: http://192.168.x.x:3000` のアドレスを確認してください。これがiPhoneからアクセスする際のアドレスになります。
3.  **アプリのインストール**:
    - iPhoneに **「NFC Tools」** アプリ (無料) をインストールしてください。[App Store Link](https://apps.apple.com/jp/app/nfc-tools/id1252962749)

### 1. iPhoneでの管理画面アクセス
1.  iPhoneのSafariを開き、確認したアドレス (`http://192.168.x.x:3000/admin/tags`) にアクセスします。
    - ※ 初回はログインを求められます。検証用に管理者権限 (`ADMIN`) を持ったユーザーでログインしてください。
2.  タグ一覧が表示されることを確認します。

### 2. URLのコピー (管理画面)
1.  一覧からステータスが **`CREATED`** (または `ACTIVE`) のタグを探します。
    - ※ まだタグがない場合は、上部の「タグ生成」フォームから数個生成してください。
2.  その行の **「書き込み情報」** ボタンをタップします。
3.  モーダルが表示されたら、URL欄の横にある **「コピー」** ボタンをタップします。
    - `コピー完了` と表示されればクリップボードに保存されています。

### 3. NFCタグへの書き込み (NFC Toolsアプリ)
1.  **NFC Tools** アプリを起動します。
2.  下部メニューの **「書く (Write)」** をタップします。
3.  **「レコードを追加 (Add a record)」** をタップします。
4.  リストから **「URL / URI」** を選択します。
5.  入力欄を長押しして、さきほどコピーしたURLを **ペースト** します。
6.  右上の **「OK」** をタップします。
7.  「書く」メニューに戻るので、**「書き込み (Write)」** ボタン (サイズなどが表示されているボタン) をタップします。
8.  「スキャン準備完了」と表示されたら、**iPhoneの上部背面（カメラの横あたり）** をNFCタグにかざします。
9.  チェックマークが表示されれば書き込み成功です。

### 4. 動作確認 (アプリ起動)
1.  iPhoneのホーム画面に戻ります（または画面をロックしてから解除）。
2.  書き込んだNFCタグに、iPhoneの上部をかざします。
3.  画面上部に **「"..."をSafariで開く」** という通知バナーが出るのでタップします。
4.  ブラウザが起動し、開発中のアプリ (`/app/activate` 画面やログイン画面) が開けば成功です！

---

### トラブルシューティング
- **「サイトにアクセスできません (localhost)」となる場合**:
    - 書き込まれたURLが `localhost` になっている可能性があります。
    - PCのブラウザからURLをコピーしたり、アプリの設定が間違っている場合に発生します。
    - iPhoneで管理画面を開いているときのアドレスバーが `192.168.x.x` であっても、コピーされるURLを確認してください。
- **ログインできない / リダイレクトでおかしくなる場合**:
    - `.env` ファイルの `NEXTAUTH_URL` が `localhost` になっていないか確認してください。モバイル検証時はPCのIPアドレス (`http://192.168.1.2:3000` など) に設定する必要があります。
