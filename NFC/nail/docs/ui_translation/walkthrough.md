# UI日本語化検証手順

変更内容が正しく反映されているかを確認するための手順です。

## 1. ランディングページの確認
- **URL**: [http://localhost:3000/](http://localhost:3000/)
- **確認事項**:
    - 「NFC Linkへようこそ」というタイトルが表示されていること。
    - 「設定へ移動」「マイページ」などのボタンが（ログイン状態に応じて）日本語で表示されていること。
    - **修正確認**: 「マイページ」ボタンをクリックし、正しいプロフィールページ（例: `/u/ユーザーID`）へ遷移すること（404エラーにならないこと）。

## 2. プロフィール設定ページの確認
- **URL**: [http://localhost:3000/settings](http://localhost:3000/settings)
- **確認事項**:
    - ページタイトルが「プロフィール設定」になっていること。
    - 各項目のラベルが「プロフィール画像」「ユーザーID」「表示名」「自己紹介」になっていること。
    - 保存ボタンが「変更を保存」になっていること。

## 3. 公開プロフィールの確認
- **URL**: [http://localhost:3000/u/aaa](http://localhost:3000/u/aaa) (またはあなたのユーザーID)
- **確認事項**:
    - リンクが登録されていない場合、「リンクはまだありません。」と表示されること。

## 4. 動作確認
- 設定ページで「変更を保存」を押し、ボタンのテキストが一時的に「保存中...」になることを確認してください。

## 5. 画像リサイズの確認（新規）
1.  **高解像度画像のアップロード**: スマホの写真など、大きなサイズ（例: 3000px以上）の画像をプロフィール画像としてアップロードします。
2.  **表示確認**: アップロード後、プロフィール画像が正しく表示され、顔が中心に来ていることを確認します。
3.  **URL確認** (可能であれば): 新しいタブで画像を開き、URLに `w_500,h_500,c_fill,g_face` などのパラメータが含まれているか、または画像サイズが500x500px程度になっているかを確認します。
