# Phase 5: サービスモデルの転換 (B2B2C化)

## 概要
アプリの役割を「個人利用」から「サロン提供型サービス」へ再定義する。
- **サロン側 (Admin)**: NFCタグの書き込み・発行・顧客管理を行う。
- **顧客側 (User)**: 自身のプロフィール修正・デザイン変更を行う。
