# Phase 5: B2B2Cモデル (サロン提供型) 検証手順

## 概要
サロンスタッフ（管理者）とお客様（ユーザー）の役割分担が正しく機能し、NFCタグの発行から利用開始までのフローが回ることを確認します。

## 1. 権限設定 (RBAC) の確認

### 管理者 (Admin)
- [ ] `http://localhost:3000/admin` にアクセスできること。
- [ ] タグ管理・書き込み機能が使えること。

### 一般ユーザー (User)
- [ ] `http://localhost:3000/app/profile` (プロフィール編集) は使えること。
- [ ] `http://localhost:3000/admin` にアクセスしようとすると、ログイン画面に飛ばされるか、拒否されること。
    - ※確認するには、別のブラウザでテストユーザーでログインするか、シークレットウィンドウを使用してください。

## 2. 接客・タグ発行フローの確認

### ステップ1: 新規タグの準備 (サロン側)
1. 管理者で `/admin/tags` を開く。
2. ステータスが `CREATED` (在庫) のタグを探す。
3. 「書き込み情報」ボタンを押す。
4. **「有効化URL書き込み」** モードになっていることを確認。
    - URL例: `.../app/activate?code=xxxxx`
5. このURLをNFCタグに書き込む。

### ステップ2: お客様への提供と登録 (お客様側)
1. スマホでNFCタグを読み取る。
2. ログイン/登録画面が開くことを確認。
3. メールアドレス等でログインすると、そのタグが「有効化」され、プロフィール編集画面になることを確認。

### ステップ3: プロフィール書き込み (サロン側)
1. お客様がプロフィールID (`handle`) を設定した後。
2. 管理者で `/admin/tags` を再度開く（リロード）。
3. さきほどのタグが `ACTIVE` になっており、お客様のハンドルが表示されていることを確認。
4. 「書き込み情報」ボタンを押す。
5. **「公開ページ書き込み」** モードに自動で切り替わっていることを確認。
    - URL例: `.../u/siro-nail`
6. この公開用URLを、再度お客様のNFCタグに上書きする。

### ステップ4: 最終確認
1. NFCタグを読み取る。
2. 今度は「登録画面」ではなく、お客様の「公開プロフィールページ」が直接開くことを確認。

## 完了
これが確認できれば、**「サロンでタグを管理し、お客様はコンテンツを管理する」** というB2B2Cモデルのシステムは完成です！
