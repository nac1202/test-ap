# オフライン・レーダー機能実装完了

インターネット回線が切断された状態でも、「大切な人の最後の位置」へ合流するためのサバイバルレーダー機能を実装しました。

## 実装された機能

1. **オフライン・モードの自動切り替え**
   - 端末が圏外や機内モードになったことを検知し、自動的に共有マップの表示を「オフライン・レーダー」へと切り替えます。
   - オンライン時でも、マップ画面右上の「コンパスボタン」をタップすることで任意のタイミングで起動可能です。

2. **iOS / Android対応の高精度コンパス**
   - HTML5 `DeviceOrientation` API を利用し、スマホが向いている方角をリアルタイムに取得します。
   - iPhone（Safari環境）の厳しいプライバシー制限に対応するため、初回起動時に分かりやすいUIで「コンパスの許可」を求めるボタンを内蔵しました。

3. **Haversine距離・方位角ナビゲーション**
   - 現在のGPS座標と、最後に保存された「相手のGPS座標」の2点間から、地球の丸みを考慮した直線距離（Haversine式）と、目的地の方位角を計算します。
   - 画面中央の大きなナビゲーション矢印が、自分がどの方角を向いても「常に相手のいる方向」を指し示すように追従回転します。

## テスト（検証）手順

1. **URLを開く**
   スマホのブラウザ（Safari または Chrome）で `https://family-safety-app-omega.vercel.app` を開いてください。
2. **共有マップ画面へ移動**
   下部メニューから「共有マップ」を開きます。
3. **レーダーの起動**
   画面右上の「コンパス（方位磁石）」ボタンをタップするとレーダーモードに切り替わります。（または機内モードにして完全にオフラインにしてみてください）
4. **センサーの許可（iPhoneの場合）**
   「コンパスを許可する」という青いボタンが表示されたらタップし、iOSのシステムポップアップで「許可」を押してください。
5. **動作の確認**
   - 画面中央の矢印が動き出し、特定の方向を指すことを確認してください。
   - スマホを手に持って**自分自身がクルクルと回ってみて**、矢印が画面内で回転し、「常に実際の現実世界における同じ方角」を指し続けるか確認してください。
   - 画面上部のタブで、案内するメンバーを切り替えられるか確認してください。

> [!TIP]
> 矢印の動きが渋い場合やずれていると感じる場合は、スマホを空中で大きく「8の字」に数回振り回すと、スマホ内部の地磁気センサーがキャリブレーション（補正）され、精度が大幅に向上します。
