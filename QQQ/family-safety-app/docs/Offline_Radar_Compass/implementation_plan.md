# オフライン・レーダー機能実装計画

災害時（通信ダウン・圏外）に備え、インターネットが繋がらなくとも「大切な人の最終位置」へ向かえるよう案内する「オフライン・レーダー（コンパスナビ）」機能を実装します。

## 背景と要点
Google Mapsは通信がないとタイル画像を読み込めず、白い画面になってしまいます。
しかし、スマホに内蔵された「GPS（宇宙からの信号）」と「電子コンパス（地磁気）」は通信レスで動きます。この2つを組合せ、「自分から見て、目標地点がどの方角に、あと何メートル離れているか」を算出して矢印で導くサバイバルレーダーを開発します。

## Proposed Changes

### `src/components/Map/OfflineRadar.tsx` [NEW]
- レーダー表示のコアUIコンポーネント。
- 現在の方位（デバイスの向き: Heading/Alpha角度）と、目的地までの距離・方位角を計算。
- 大きな矢印を中心に置き、目的地の方向へ矢印が回転するUI。

### `src/hooks/useCompass.ts` [NEW]
- HTML5の `DeviceOrientation` APIを使って、デバイスの向いている方角を取得・監視するカスタムフック。
- iOS (Safari) 特有のプライバシー保護機能による「コンパスの使用許可リクエスト（`requestPermission`）」のロジックをカプセル化。

### `src/utils/geoCalculations.ts` [NEW]
- **Haversineの公式**: 2つの緯度経度から「直線距離（メートル）」を計算する関数。
- **方位角の計算 (Bearing)**: 2つの緯度経度から、目的地が「北から何度の方角にあるか」を計算する関数。

### `src/hooks/useNetworkStatus.ts` [NEW]
- ブラウザの `onLine` や `offline / online` イベントをリッスンし、現在通信可能かどうかを返すフック。

### `src/app/map/page.tsx` [MODIFY]
- 作成した `useNetworkStatus` を組み込み。
- オンライン時：通常のGoogle Mapsを表示。ボタンで「レーダーモード（コンパス）」も起動可能にする。
- オフライン時：自動でマップを隠し、「レーダーモード（オフラインコンパス）」に切り替える。または「オフラインのため地図は表示できません。最後の位置へのレーダーを起動しますか？」というUIを出す。

## Verification Plan
1. 【開発ログでの検証】PCブラウザのDevToolsを使用して緯度経度・方角のモック数値を流し、計算通りに矢印の角度が変わるか・距離が正しく表示されるかを確認する。
2. 【実機確認の依頼】ユーザーにスマホからアクセスしていただき、スマホを持って自分がクルクル回ったときに、正しく特定の方角（北や指定したダミーポイント）を矢印が指し続けるか確認して頂く。
3. 【オフラインテスト】機内モードに切り替えたときに、マップがレーダー画面にフォールバックすることを確認する。
