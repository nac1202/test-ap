# 公式避難所データの統合 実装計画

## 背景
Google Mapsの検索結果だけでなく、国土地理院 (GSI) などの公式な指定緊急避難場所データを統合し、ユーザーに信頼性の高い避難所情報を提供する。

## 実装内容
1. **データ取得・判定ロジック**
   - 既存の `NearbyShelters.tsx` にGSIデータの判定ロジックが組み込まれているか確認。
   - `google.maps.places` の結果と、公式リスト（静的データまたはAPI経由）を照合する。

2. **UI表示の改善**
   - リストアイテムや地図上のマーカーに「公式指定」であることを示すバッジ等を追加。

3. **バグ修正**
   - 統合に伴う型エラー (TS) やインポートエラーがないか確認し修正する。
