# ホーム画面ガイドボタン統合計画

## ゴール
ホーム画面上の「防災ガイド」「救護ガイド」「防犯・護身ガイド」の3つのボタンを統合し、1つの大きなボタンにします。これにより、ホーム画面をすっきりさせ、全ての知識・ガイド情報への一本化された入り口を提供します。

## ネーミング案
ユーザー提案の「お役立ちガイド」も良いですが、アプリのテーマ（安全・安心）に合わせた以下の案も検討します。

1.  **あんしんガイド** (採用案)
    - 理由: 「防災」「防犯」「救護」すべてが「安心」につながるため。柔らかい響きで親しみやすい。
2.  **知識・マニュアル**
    - 理由: 機能的だが少し硬い。
3.  **セーフティガイド**
    - 理由: アプリ名「Kizuna Safety」と親和性が高い。
4.  **お役立ちガイド** (ユーザー案)
    - 理由: 分かりやすいが、少し一般的すぎる可能性も。

今回は **「あんしんガイド」** を第一候補として提案し、サブテキストで「防災・防犯・救護の知識」と補足する形を推奨します。

## デザイン変更

### [変更] `src/app/page.tsx`
- 既存のグリッドレイアウト（防災・救護の2カラム + 防犯の全幅）を削除。
- 他のメイン機能（安否報告、共有マップ、避難所リスト）と同じスタイルの、全幅カードコンポーネントを追加。
- **色**: 緑色（Green）を基調とする（知識・安全のイメージ）。
    - 背景: `bg-green-50`
    - アイコン: `BookOpen` (Green-500)
    - テキスト: `text-slate-800` / `group-hover:text-green-600`

## 検証計画
- ホーム画面でボタンが1つになっていることを確認。
- ボタンクリックで `/guide` に遷移することを確認。
- `/guide` ページでタブが表示され、他のガイドにもアクセスできることを再確認。
