# テーマ調整ウォークスルー (Teal -> Cyan)

## 概要
アプリケーションのプライマリテーマをTealからCyanに更新しました。この視覚的な刷新により、すべての機能を通じて、よりクリーンで「青みのある」美観を提供します。

## 変更点

### 1. グローバルナビゲーション
- **Navbar**: ヘッダーの背景色を `bg-cyan-600` に更新しました。
- **BottomNav**: アクティブタブの色を `text-cyan-600` に変更しました。

### 2. トップページ
- **ヒーローセクション**: 背景グラデーションとテキストをCyanを使用するように更新しました。
- **アクションカード**: 「共有マップ」カードでCyanのアクセント（`bg-cyan-50`, `text-cyan-500`）を使用するようにしました。

### 3. 避難所 (Shelter) 機能
- **Shelterページ**: 「検索」と「追加」ボタンをCyanに更新しました。
- **周辺の避難所 (Nearby Shelters)**:
  - 検索入力のフォーカスリングをCyanにしました。
  - 「検索」ボタンをCyanにしました。
- **避難所リスト (Shelter List)**:
  - アイコンと空の状態のイラストにCyanを使用しました。
- **修正**: 重大なHTML構文エラーとインポートの問題を解決しました。

### 4. 安否確認 (Safety) 機能
- **ステータスフォーム**: 送信ボタンを `bg-cyan-600` に更新しました。
- **チェックインボタン**: フォーカス状態にCyanのリングを使用するようにしました。

### 5. マップ (Map) 機能
- **ロケーションマップ**: ユーザーの現在地マーカーをCyanのカラーコード（`#0891b2`）に更新しました。

### 6. ガイド (Guide) 機能
- **検索**: Cyanのフォーカスリングを持つ検索バーを追加しました。
- **ガイドリスト**: カテゴリータグとホバー効果でCyanを優先するように更新しました。
- **ナビゲーション改善**:
  - `GuideTabs` コンポーネントを作成し、防災・救護・防犯の各ガイドをタブで切り替えられるようにしました。
  - ホーム画面の3つのガイドボタンを1つの「あんしんガイド」ボタンに統合し、アクセスを簡素化しました。
  - ボトムナビゲーションの「ガイド」ラベルを「安心ガイド」に変更しました。
