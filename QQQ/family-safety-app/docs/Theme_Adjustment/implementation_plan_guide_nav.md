# ガイドナビゲーション改善計画

## ゴール
「ガイド」メニューが「防災ガイド」のみを表示している現状を改善し、防災・救護・防犯の各ガイドへ簡単にアクセスできるようにします。これにより、ユーザーが「ガイド」タブから全てのガイドコンテンツにアクセスできるようになり、ホーム画面との整合性を高めます。

## ユーザーレビュー要
特になし

## 変更内容

### コンポーネント作成
#### [新規] `src/components/Guide/GuideTabs.tsx`
- 防災ガイド (`/guide`)、救護ガイド (`/firstaid`)、防犯・護身ガイド (`/security`) へのリンクを持つタブナビゲーションを作成します。
- 現在のページに応じてアクティブなタブスタイルを適用します。

## 検証計画
- ブラウザで `/guide` にアクセスし、新しいタブが表示されるか確認する。
- タブをクリックして、各ガイドページへスムーズに遷移できるか確認する。
- アクティブなタブが正しくハイライトされるか確認する。
