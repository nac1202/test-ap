# プッシュ通知設定機能の実装計画

ユーザーからご提示いただいた画像のような、各種災害・警報の「プッシュ通知設定（ON/OFF）」画面を実装するための計画です。

## 実装内容

### 1. 通知設定ページ（UI）の開発
*   **パス**: `src/app/settings/notifications/page.tsx`
*   **デザイン**: ご提示いただいた画像を参考に、緑色と白を基調としたシンプルで分かりやすいトグルスイッチ（ON/OFF）の一覧画面を構築します。
*   **実装項目**: 以下の7つの項目を設定できるようにします。
    1. 緊急地震速報
    2. 地域別警報
    3. 大雨危険度通知
    4. 天気
    5. 不審者情報
    6. 大津波警報
    7. 津波警報

### 2. トグルスイッチ（Switch）UIとフックの作成
*   **コンポーネント**: 滑らかなアニメーションを持たせたモダンなON/OFFスイッチを独自にTailwind CSSで実装します。
*   **状態保存**: ユーザーが設定したON/OFFの各状態をブラウザの `localStorage` または `Cookie` に保存し、アプリを再起動しても設定が維持されるようにします。（将来的にはバックエンド連携用データになります）

### 3. 画面への導線（リンク）追加
*   **ナビゲーション**: ヘッダー等に設定ボタンを配置するか、各種メニューからこの「通知設定」画面へアクセスできるように構成します。

## ユーザー確認事項
*   現状はプッシュ通知のバックエンド送信システムとは未接続のため、**「画面上で設定の個別ON/OFF状態を切り替えられ、それを保存する」部分まで**のUIとフロントエンドのロジック実装となります。
*   レイアウトなどは基本的に画像のテイスト（緑色のタイトルバー、白い背景のリスト、緑色のスイッチ等）に沿って作成いたします。
