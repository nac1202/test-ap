# リアルタイム災害・警報連携 実装計画

## 概要
スマートフォンのGPS（現在位置）をもとに、現在いる地域の「災害情報（地震、台風など）や気象警報・注意報」をリアルタイムで取得し、アプリ上に表示する機能を実装します。

## アーキテクチャと使用API
完全無料で利用できる以下のAPIを組み合わせて実現します。

1. **Google Maps Geocoding API**
   - 緯度・経度から「●●県●●市」といった住所（都道府県名）を取得します（すでにAPIキー設定済みのため流用します）。
2. **気象庁 (JMA) 防災情報 JSON API**
   - 気象庁がWeb公開しているJSONデータを利用します。
   - `都道府県コード.json` を叩くことで、該当地域に現在発令されている警報・注意報（大雨警報、洪水注意報など）をリアルタイムに取得します。

## 主要な実装ステップ

### 1. 逆ジオコーディングとJMAコード変換
- 現在地の `lat, lng` を Google Maps API に渡し、都道府県（例：`東京都`）を取得します。
- `東京都` という文字列から、気象庁API用のエリアコード（例：`130000`）に変換するマッピングデータ（辞書型）を作成します。

### 2. アラート取得用カスタムフックの作成 (`useDisasterAlerts.ts`)
- JMAエンドポイント `https://www.jma.go.jp/bosai/warning/data/warning/{area_code}.json` へフェッチを行う専用フックを作成します。
- その県で出ている警報の中から、逆ジオコーディングで判明した「市区町村」に該当する警報コード群のみをフィルタリング抽出します。

### 3. アラート表示コンポーネントの実装 (`DisasterAlertBanner.tsx`)
- 画面上部（ナビゲーションバーの下など）に固定表示されるバナーコンポーネントを作成します。
- [赤色: 特別警報・警報]、[黄色: 注意報] のように、レベルに応じた色分けUIで目立つように表示します。

### 4. 画面への組み込み
- ホーム画面 (`/`) や 安否確認ページ (`/safety`) に `<DisasterAlertBanner />` を設置し、外出時や避難時に必ず目に入るようにします。
