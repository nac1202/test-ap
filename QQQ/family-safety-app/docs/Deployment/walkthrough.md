# デプロイ (Vercel) 確認 Walkthrough

## 実施内容
- `vercel` CLI をグローバル環境にインストールし、プロジェクトのビルドおよびデプロイを実行しました。
- アプリで利用している Google Maps API キー（`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`）をVercelの環境変数として登録し、再デプロイを行いました。
- すべてのビルドプロセスがエラーなく完了し、本番用URLが発行されました。

## デプロイ情報
- **公開用URL**: [https://family-safety-app-omega.vercel.app](https://family-safety-app-omega.vercel.app)

## 次のステップ (ユーザーによる実機テスト)
スマートフォン等のブラウザで上記の **公開用URL** にアクセスし、以下の動作確認をお願いします。

1. **全体的なUI/デザイン**の表示崩れがないか。
2. **位置情報の取得許可**を求められ、許可後に「家族マップ」および「周辺の避難所を探す」にて位置情報が反映されるか。
3. 避難所リストにおいて、国土地理院データに基づく **「指定避難所」バッジ** が表示されるか（現在地周辺、または新宿区などの検索結果）。
